グラスが出している画像

196 × 196 / 実寸

これが `sendImage` に渡す中身そのもの。グレースケールで 196×196 に描き、3bit（8 階調）へ量子化してから緑へ写している。上の視界にはこれを引き伸ばして重ねているだけで、描き直してはいない。

階調は 0〜7 の 8 段。等級を明るさだけで表すと潰れるため、点の大きさと組み合わせている。

忠実でないところ

パネルの画角が未確認

表示パネルが 576×360 画素であることは SDK 0.2.0 のキャンバスから分かったが、それが視野の何度を占めるかは未確認。初期値 34° は仮置き。

196×196 の出かたが未確認

パネルのどこに、等倍で出るのか拡大されるのかが分からない。点線がパネル、実線が画像。切り替えて両方見られるようにしてある。

緑の色味は仮

rgb(56,255,116) は一般的な緑マイクロディスプレイを想定した値。実機を見て決める。

量子化の中身は不明

SDK 側がディザをかけるかどうか分からないので、単純な 8 段丸めにしている。

景色は作りもの

建物と稜線は方位から決まる手続き生成。実在の地形ではないが、遮蔽の起きかたを見るには足りる。
