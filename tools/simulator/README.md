# 天球シミュレータ

**SABERA の実機で確かめる前に、ブラウザで変換パイプラインを検証する。**

## 使う

`index.html` をブラウザで開くだけ。ビルドもローカルサーバーも要らない。

```console
open tools/simulator/index.html          # macOS
```

## 画面の見かた

**上の大きな画面は「かけている人に見えるもの」。** 肉眼で見える空と地上の景色を背景に、
グラスの表示面を実際の画角で重ねている。**点線が表示パネル（576×360）、実線が星図を描いている領域**。

**下の画像は `sendCanvasImage` に渡す中身そのもの。** 上の視界にはこれを引き伸ばして
重ねているだけで、描き直してはいない。

**星座名は画像に焼いていない。** SDK 0.4.0 から画像とテキストが共存できるので、
`sendCanvas` のテキストとして画像の手前に重ねている（ファーム側が描くので量子化を通らない）。
`sendCanvas` の上限に合わせて **視野中心に近い順に 8 個まで**にしている。

## 何が忠実で、何がそうでないか

**忠実：**

- **グラスの画像は選んだサイズで描く。** 拡大表示はそれを引き伸ばしただけ
- **緑単色の 8 階調**（3bit）へ量子化してから緑へ写している（順序も実機どおり）
- **黒は透明。** 波導ディスプレイなので暗い画素の向こうに景色が透ける。加算合成で再現している
- **表示パネルは 576×360**（SDK 0.2.0 のキャンバスの座標系から判明）
- **星図の描画サイズを選べる** — 512×320（画像バッファに入る最大、0.4.0）／320×320／196×196（退路）
  - **576×360 は選べない。** 画像バッファは `w × h × 2` の合計で 380,000 バイトまでで、
    576×360 は画素だけで 414,720 になる（SDK が `require` で弾く。実機で確認）
- **星座名は画像とは別のテキスト。** 画像の手前に描かれる（0.4.0 の仕様どおり）
- **表示面は視界の一部**。パネルの画角を変えると見かけの大きさが変わる
- **地上の遮蔽**。建物や稜線に隠れる星は描かない
- **光害と大気減光**。市街地では 4 等がやっと、地平線近くではさらに暗くなる
- 座標変換は [座標変換パイプライン](../../docs/team-e/coordinate-system.md) のとおり
  — 歳差（Meeus 21.4）→ 恒星時 → 地平座標 → ステレオ投影
- 投影・ロールは仕様で決めたとおり（ステレオ投影・地平線水平固定）

**忠実でない：**

- **パネルの画角が未確認。** 画素数（576×360）は分かったが、視野の何度を占めるかは別問題。
  初期値 34° は仮置き
- **ラベルの見え方は推測。** フォント・大きさ・階調が実機とどう違うかは分からない
  （`SettingKey.FONT_SIZE` でも変わる）
- **転送時間を再現していない。** 大きい画像ほど表示まで時間がかかるはずだが、ここでは一瞬で出る
- 緑の色味 `rgb(56,255,116)` は仮の値。実機を見て決める
- SDK 側の量子化アルゴリズム（ディザの有無など）は不明なので、単純な 8 段丸めにしている
- **景色は作りもの。** 建物と稜線は方位から決まる手続き生成で、実在の地形ではない
- 表示の応答速度・転送時間は再現していない
- 月・惑星・天の川は描いていない

## 見つかること

**星図に詰める画角と、星図が実際に占める画角が違うと、緑の星図は空と一致しない。**

視界に重ねる体験を狙うなら、この 2 つを揃える必要がある。ずれていると画面に警告が出る。

**SDK 0.4.0 でこの制約はゆるんだ。** キャンバスの画像は 512×320 まで置けるので、
**パネルのほぼ全面を星図に使える**。0.2.0 時点では 196×196 がパネルの 34% しか占めず、
重ねるなら星図 FOV が 12° 程度に縛られていた。

「星図を描くサイズ」を 512×320 と 196×196 で切り替えると、その差がそのまま見える。

## 確かめられること

| 見たいこと | 操作 |
|---|---|
| **星図が実際の空と重なるか** | 表示面の画角と星図の画角を揃える／ずらす |
| **市街地でも星座が分かるか** | 景色を「市街地」にする。光害で 4 等までしか見えなくなる |
| **建物にどれくらい隠れるか** | 視線の高度を下げる |
| 限界等級と FOV の組み合わせで潰れないか | スライダーを動かす |
| 歳差を入れる価値があるか | チェックを外すと 0.36° のずれが出る |
| **星座名が読めるか・8 個で足りるか** | 「星座名を出す」を入れる。テキストなので画像とは別に重なる |
| 季節・時刻・観測地で何が見えるか | 日時と観測地を変える |
| 星座の形がステレオ投影で保たれるか | 星座を選んで視野を移す |

## 作り直す

`data/` を更新したら再生成する。

```console
python3 tools/build-simulator.py            # 作り直す
python3 tools/build-simulator.py --check    # 最新か確かめる
```

- 中身をいじるなら `template.html` を直す。**`index.html` は生成物なので直接編集しない**
- `template.html` の `__STARS__` / `__CONS__` / `__BRIGHT__` に `data/` の JSON が差し込まれる
