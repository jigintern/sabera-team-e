# team-e

星座と視覚を重ね合わせ、AI に頼むと今見えている星座を解説してくれるアプリの仕様。

| ドキュメント | 中身 |
|---|---|
| [座標変換パイプライン](coordinate-system.md) | 星表の座標からグラスの 576×360 画素までの変換 |
| [画面遷移とジェスチャー](app-flow.md) | 何を触ると何が起きるか、そのとき何が出ているか |
| [人工衛星モードの調査](satellites.md) | 星座と切り替えて衛星を出す。軌道計算とデータの当て |

図は `diagrams/` の `.drawio.svg`。**そのまま draw.io で開いて編集できる。**

## いまどこまで動いているか

`samples/kmp/app` のプロトタイプで、**グラスに星図を出して首の向きに合わせて描き直す**
ところまで実機で動いている。

| できていること | 補足 |
|---|---|
| 星図をキャンバスに出す | 528×330。星座名はテキストで手前に重ねる |
| 首の向きに合わせて描き直す | **止まってから 1 枚**。転送中は前の絵が消えるため |
| 方位合わせ | グラスの十字とスマホのマーカーを重ねる |
| 観測地の測位 | 融合 → GPS → 基地局。取れなければ手入力 |

| まだ無いもの |
|---|
| 星座の同定（IAU 境界）とジェスチャーでの問いかけ |
| AI の解説と読み上げ |
| 天体アライメント（地磁気の誤差を消す） |

技術的な前提と SDK の制約は [AGENTS.md](https://github.com/jigintern/sabera-team-e/blob/main/AGENTS.md)。
