# team-e

**空にかざしたグラスの視界と星座を重ね、AI に頼むと今見えている星座を解説してくれるアプリ**の仕様。
星座と切り替える**人工衛星モード**も作っている。

| ドキュメント | 中身 |
|---|---|
| [グラス出力の制約](glass-output.md) | 何をどれだけ出せるか。**両モード共通の土台** |
| [座標変換パイプライン](coordinate-system.md) | 星表の座標からグラスの画素まで。方位合わせ・星座判定・星表データ |
| [画面遷移とジェスチャー](app-flow.md) | 何を触ると何が起きるか。スマホ UI・AI 解説 |
| [人工衛星モード](satellites.md) | 軌道計算・衛星の選定・動くものの描き方 |
| [実機確認の手順](field-check.md) | **何を持って外に出て、どの数字が出たら合格か。** ログの取り出し方 |
| [星図を空に重ねる精度](alignment-accuracy.md) | 天体アライメント・画角・ロールの計画。**UX を優先して見送った記録** |

## 動いているもの

実装は `samples/kmp/app`。

| | 状態 |
|---|---|
| 星図をキャンバスに出す | **実機で確認済み。** 528×330。星座名はテキストで手前に重ねる |
| 首の向きに合わせて描き直す | **実機で確認済み。** 止まってから 1 枚（転送中は前の絵が消える） |
| 方位合わせ（スマホ同期・これだけ） | **2026-08-21 に実機で確認済み。** ヨーの符号を修正し、揃ったまま 2 秒で**自動確定**（押させない）。条件が渋いときは「この精度のまま観測へ」で進める |
| 磁気の歪み検知 | **実装・JVMテスト済み。** 期待値と比べて**警告する**（止めない）。机の上では常に歪む |
| 月・惑星の位置計算 | **実装・JVMテスト済み（10件）。** 日食・大接近・衝で 0.05° 一致 |
| 星図への月・惑星の描画 | **実装・JVMテスト済み。** 月は輪、惑星は恒星と同じ点。名前は星座名より優先 |
| AI 解説への月・惑星 | **実装・JVMテスト済み。** 根拠に渡し、視野に無い天体を語る文は落とす |
| 画角 | **仮の 35° 固定**（`ObservationDefaults.STAR_MAP_FOV_DEG`）。**実測も設定 UI も入っていない** |
| 観測地の測位 | **実機で確認済み。** 融合 → GPS → 基地局。取れなければ手入力 |
| AI の解説と読み上げ | **従来経路は実機で確認済み。** PCM整列＋全文バッファ再生、根拠検査、途中切断からの復帰はJVMテスト済み、**実機確認待ち** |
| AI 解説の主役 | **2026-08-21 に実機で確認済み**（#37）。**グラスに出したラベルの先頭**（視野中心に近い星座）で、絵と根拠を 1 回の描画から作る |
| 星座の同定（IAU 境界） | **実装・JVMテスト済み。** Roman (1987) 357行＋B1875歳差変換。**ラベルが出ない方向の代用に格下げ** |
| 衛星の軌道計算と描画 | **JVM テストのみ。** SGP4/SDP4 は参照実装と 4mm 差。**実機での見え方は未確認** |
| `DOUBLE_TAP` でのモード切り替え | **実機未確認** |
| 設定画面からの明るさ調節 | **実機で調整中。** 手動5段階を送り、直前の星図を再送して反映する |

## まだ無いもの

| | 補足 |
|---|---|
| 画角の実測 | 仮の 35° のまま。**測る仕組みごと外してある**（視野端のずれに直接効く） |
| ロール追従 | 地平線を水平に固定している。**首を傾けた分そのまま形が回る**（端で 1.5〜4.6°） |
| 加速度軸の自動判定 | ロール追従の前提。**外してある** |
| 調整・計測用の画面 | 画角スライダー・目印・ロール追従スイッチ・自己診断ログ。**外してある** |
| パス予報 | いま空にいない衛星が次に来るのはいつか |
| 天体アライメント | **見送った。** 精度より UX。星座の同定（±20°）はスマホ同期で足りる（[記録](alignment-accuracy.md)） |
| ジェスチャーの再配分 | 3 枠が埋まっていて「もっと詳しく」の行き先が無い |
| 旧ファーム向け画像表示ページ | 196×196 の退路は設計済みだが、アプリへの切り替え経路は未実装 |
