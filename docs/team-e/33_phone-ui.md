# スマホの画面

**同伴者と、詰まったときのための画面。** かけている人はここを見ない。
役割分担は [役割分担と画面遷移](30_app-flow.md)、グラス側は
[グラスに出す画面](32_glass-screens.md)、ガイドの画面は [星座ガイド](37_guide.md) と
[ガイドの台本を作る・配る](39_guide-authoring.md)。

## 画面の構成

**ホーム → 接続 → 方位合わせ → 星図**の 4 画面と、ホームから開く**ガイド**（一覧・詳細エディタ・
配る・受け取るの 4 枚）。星図の画面が本体で、
**上部バーの「設定」で設定ページへ移り、そこから開発者用画面へ入る**
（**メイン → 設定 → 開発者用の 3 面**。戻るは 1 段ずつで、どこからでも 2 回で星空へ帰る）。
衛星の重ねはスマホの設定だけにある
（空を見ている人はスマホを見ないので、上のバーに常設しない）。
**解説または案内中だけ終了ボタンがバーに出る**（設定を開いていても止められる）。

**ホームには今日のひとことを出す**（グラスの挨拶画面と**同じ 1 つ**を `GlassesApp` で作って
両方へ渡す。別々に作ると、かけている人と覗いている人で違うことが書いてある画面になる）。
**グラスがつながっていなくても出す**（ホームはつなぐ前に開く画面）。
**置くのは「星空を、もっと身近に。」とスタートの間。** 下端に寄せていたときは、
押したあとに気づく位置で読まれなかった。**その高さは最初から空けておく**
（あとから足すと、読み込みが終わった瞬間にボタンが飛び上がって押す先が動く）。

ホーム・接続・星図は縦横に対応し、方位合わせだけはセンサー軸の誤認を避けるため縦画面に固定する。
ホームと接続は内容を中央へまとめる。横の星図は左半分にプレビュー、右半分に解説と操作を置き、
設定を開いても左のプレビューを残す。解説本文だけをスクロールし、解説開始と方位合わせのボタンは
常に右下へ残す。縦の設定ではプレビューを中央に置く。

**横では上部バーを出さない。** 全幅 64dp のうち右半分が空のまま残り、そのぶん解説と設定が
低くなる（横の縦幅は 350dp ほどしかない）。タイトルと「戻る」は左ペインの頭、
**終了ボタンと「設定」は右ペインの頭（画面の右上）**に置き、左右を同じ高さで並べる。
こうすると見た目は 1 本のバーのまま、使う高さは 1 行ぶんで済む。操作はスクロールの外に残す。
**右ペインは画面のてっぺんから始め、下端は背景の星座名に譲る**
（`BACKGROUND_LABEL_CLEARANCE`）。設定側は 85% の板を敷くので、下まで伸ばすと
右下の「◯の星座・◯◯座」が板の裏に隠れる。

**案内とガイドの札は解説と同じ右側に置く。** 横で左のプレビューへ積むと縦幅に収まらない。

```
┌─────────────────────────────┐
│ ★ 星空     [解説を止める][⚙]│  ← 左上は星導の印。設定は歯車
├─────────────────────────────┤
│  グラスに表示している星空      │
│  ┌───────────────────────┐  │  ← 送った画像そのもの（緑 8 階調に寄せた色）
│  │        · ·  ·         │  │     名前はグラス側が描くのでここには出ない
│  └───────────────────────┘  │     出す前は「何を待っているか」を回して出す
│  グラスの向きを止めると更新    │
├─────────────────────────────┤
│ 星空の条件                   │  ← 畳んである。開くと時刻のつまみ・場所・時代
├─────────────────────────────┤
│ さそり座                     │  ← 名前は動かない
│ 狩人オリオンを刺した、さそり…  │     本文だけが枠の中を流れる
├─────────────────────────────┤
│  [ この星空を解説する ]       │  ← ここから下は流れない
│  [ ガイドを始める ]           │     （台本があるときだけ）
│  [ 方位を合わせ直す ]         │
└─────────────────────────────┘
```

| 要素 | 中身 |
|---|---|
| プレビュー | グラスに送った画像そのもの。**同伴者に見せる用途にもなる**。**描かれていない黒は落とす**（中心と縦横比は変えずに切る）。夜空はほとんどが黒で、そのまま出すと画面の大半が黒い板になる。**画面の上に固定**して、流れるのは条件と解説だけ |
| 送信中の札 | **出さない。** 0.4 秒ごとに出ては消えるので、見せたい絵より札のほうが目に付く |
| 待ちの表示 | 星表・TLE・測位・転送。**何を待っているかを書く** |
| 案内カード | 案内中だけ、対象名・「まず左右／次に上下」・角距離・「もう少し」・終了ボタン。プレビューにもグラスと**同じ形・同じ大きさ**で矢印と到着リングを重ねる（**プレビューだけ見やすくしない**） |
| 時刻を動かす | **つまみだけ**（±12 時間・15 分刻み）。つまんでいる間は着地の時刻を出す。**自動送りは点滅するので置かない**。置き場所は「星空の条件」の中 |
| 星空の条件 | **選ぶだけで決まる**（時刻のつまみ・場所・時代・時刻）。**数字を打つ欄は置かない**。**場所・時代・時刻は 1 行に畳む** — 押した 1 つだけ下へ開き、選ぶと閉じるので**開いても 2 行**（3 つとも並べると選択肢だけで画面が埋まる。場所は 19 個ある）。**「この空を見る」を押すと区画ごと畳む** — 出したばかりの空が選択肢の裏に隠れないようにするためで、ここが元の画面へ戻る口も兼ねる。**解説の上に置く** — 畳んでいれば 1 行なので解説を押し下げない。「いま何の空を見ているか」が先に目に入るほうが、解説を読む前提が揃う。押すものは「この空を見る」1 つに見せ、「現在の空に戻る」は枠を持たない文字にする。**設定ではなくメインに置く** — 「いま何を見るか」の操作だから |
| 解説 | **名前は枠の上に出したまま、本文だけが枠の中を流れる。**高さは**上限だけ**決める（押すものは下に貼り付けてあるのでボタンは動かない。決め打つと、数文しかない解説の下に空の帯が残る）。見出し（「星座解説」）は置かない — 名前と二重になり、本文に使える高さが減る |
| 下の 3 つのボタン | **解説する・ガイドを始める・方位を合わせ直すは画面の下に固定**（流れる中身の外）。**メインは 1 画面に収め、流れるのは星空の条件と解説だけ**。**3 つとも必ず画面のいちばん下**。中身が短くても上げない — 押す場所が中身の量で動くと、暗い屋外で毎回探すことになる。空くのは星空を出している背景で、**カードの中に空の帯を作らない**（解説の枠は上限だけ決める）。方位合わせは押す機会がいちばん少ないので下端だが、**流れて消えると、ずれに気づいたときに探させる**ことになる |
| 今夜見た星座 | 解説した星座と本文。**もう一度**で読み直す（声も鳴らし直す）。1 つも無ければ出さない |
| ガイド | **「ガイドを始める」から台本を選ぶ**（ダイアログ）。**台本が 1 つも無いときは「ガイドを作る」になり、作る画面へ送る**（押しても何も起きないボタンにしない）。作る画面から戻ると**入ってきた画面へ返る** — 観測中に作りに来た人をホームへ落とすと方位合わせからやり直しになる。想定した夜と違えば**始める前に知らせる**。流れている間は進み具合と「次へ／もう一度」（[guide](37_guide.md)） |
| 設定ページ | **触る順に並べる。** **見え方 → グラスの明るさ → 声 → 曲 → ガイドを作る → 「開発者用画面」**。数字とログは置かない。**出典はいちばん下に極小の 1 行**（区画にしない）。**プレビューは置かない** — メインの上に固定で出ているので、同じ絵を 2 か所に持たない |
| 開発者用画面 | 設定のいちばん下の**「開発者用画面」**から入る。今夜見た星座 → 声のやり取り → 下敷きの濃さ → 観測の状態 → 記録（ログ）。**戻ると設定へ帰る**。夜の屋外で触るものではないので、設定から 1 段下げた |

## 設定 — 開いておくもの・畳むもの

**屋外で触るのは空の濃さ・明るさ・音量の 3 つだけ。** 区画を 9 つとも 1 ページに並べていたときは、
いちばん効く空の濃さが画面の外へ流れていた。**設定に残すのはその 3 つと出典だけ**にして、
記録と数字は開発者用画面、場所・日時はメインへ分けた。**畳んだ区画も見出しに要約を出す**ので、
開かずに状態は読める（6DoF が受信中か、いま何等まで描いているか）。

| 区画 | どこ | 既定 | 見出しに出す要約 |
|---|---|---|---|
| **見え方**（空の濃さ・星座絵・目印・衛星） | 設定 | **開く** | 空の濃さと限界等級 |
| **グラスの明るさ** | 設定 | **開く** | 自動か手動か・段 |
| **声**（読み上げの音量・AI 音声か端末か） | 設定 | **開く** | 鳴るのはスマホのスピーカー |
| **曲**（BGM の音量・入切・曲の指名） | 設定 | **開く** | いま鳴っている曲 |
| 下敷きの濃さ | 開発者用 | 畳む | 段（グラスは緑 8 階調） |
| 星空の条件（場所・時代・時刻） | **メイン** | 畳む | いまの空の状態 |
| 今夜見た星座／声で聞いたこと | 開発者用 | 畳む | 件数 |
| 観測の状態（6DoF・方位合わせ・観測地） | 開発者用 | 畳む | **6DoF の受信と方位のばらつき** |
| 記録（ログ） | 開発者用 | 畳む | 溜まったバイト数 |
| 出典（CC BY の帰属） | 設定のいちばん下 | — | **区画にしない。極小の 1 行** |
| 下敷きの濃さ／声と曲／緯度経度の手入力 | **区画の中でさらに畳む** | — |

- **開閉は覚えない。** パネルを閉じたら畳んだ状態に戻る。
  **次に開いたときもコンパクトなのが既定**でないと、畳んだ意味がなくなる
- **アイコンを添える。** 暗い屋外では文字より形のほうが速く見つかる
  （`material-icons-extended`。未使用ぶんは R8 が落とす）
- **出す／出さないの 3 つ（星座絵・目印・衛星）は 1 行の札にする。**
  出しているかは色で分かるので「星座絵: 出す」という文まで要らない
- **札は 1 つずつ枠で囲み、間を空ける。** 詰めて並べると、隣り合って入っているときに
  **敷いた緑がつながって 1 本の帯に見え、どれが入っているのか読めない**
- **音量は左のアイコンが入／切を兼ねる。** BGM のスイッチと音量つまみで 3 行使っていた
- **声と曲は別の区画にする。** 下げたいのがどちらなのかは場面ごとに違うのに、
  1 つの「音」に押し込むと、開いてから読んで選ぶことになる
- **見え方は 2 行だけ**（濃さの段・出す／出さないの 3 つ）。細かい濃さは開発者用へ送った
- **畳むのであって、消さない。** 緯度経度の手入力もログも
  [field-check](60_field-check.md) の手順が指す先なので、辿り着けなくしない

**明るさは手動 5 段階のスライダーだけ**を置く。SDK から現在値を読み戻せないため、表示するのは
**このアプリが最後に送った値**。段階が変わると自動調整を無効化して値を送り、直前の星図を
再送して見た目へ反映する。ドラッグ中の値をすべて転送キューへ積まないよう、最新値だけをまとめる。

- **見出しの中身を見出しどおりにする。** 以前は「ログ」という 1 枚のカードの中に
  星座絵・目印・声・BGM・音量まで入っていた。**BGM を切りたい人はログを開かない**ので、
  触れるはずの設定に辿り着けなかった
- **眺めるだけの情報は設定ページに置かない。** 空の状態・月齢・空にいる衛星の一覧・
  これから来るパスは、**触れない行**として並ぶだけで、触るはずの設定を下へ流していた。
  空を見ている人はスマホを見ないし、同伴者も操作に使わない行は読み飛ばす
- **位置と時刻を出すのは、間違っていても星図が「それらしく」出てしまうから。**
  タイムゾーンの取り違えは 135°、時計の 1 時間ずれは 15°。
  どちらもユーザーには気づけず、「AI が間違っている」と誤解される
- **平常時の上のバーに置くのは「設定」だけ。** 衛星の切り替えは設定に置く。
  解説・案内中だけ終了ボタンを一時的に足す

## ガイドの口（[再生](37_guide.md) / [作る](39_guide-authoring.md)）

- **ガイドの台本を作るのはホームから**（`ui/GuideScreen.kt`）。**グラスが要らない**ので、
  出かける前に用意できる
- **詳細エディタ（toB）は一覧のいちばん下に畳む。** リース先の旅行会社向けなので、
  ふだんは目に入らない。ただし**隠し操作にはしない**（口頭で伝える運用になり、
  担当者が代わると失われる）
- **受け取る口は畳まない。** 客が使うものなので、一覧にそのまま出す
- **想定した夜と違う夜に始めるときは、始める前に確認を挟む**（[guide](37_guide.md)）
- **始めるのは畳んだ側のボタンから。** 設定パネルの中に置いていたときは、
  「設定」を押し、区画まで送って「始める」を押す**3 手**だった。空の下で押すものは、
  **開いている画面のまま押せる**ところに置く。**始める口はここ 1 つだけ**にする
- **ボタンではなくダイアログで選ばせる。** 台本が増えてもメイン画面は太らない
  （押すものは常に「ガイドを始める」の 1 つ）
- **台本が 1 本も無いときはボタンを出さない。** 押しても何も選べないボタンは置かない
- **止める口を 2 つ並べない。** ガイド中は主ボタンが「ガイドを止める」に変わるので、
  進み具合のカードには「次へ」「もう一度」だけを置く（送るつもりで止めてしまう）
- **解説のカードはボタンの上**（音声が使えない環境ではテキストが主役になる）

## 観測中の作法（消灯・戻るキー・回転）

- **観測中はスマホを消灯させない。** 音の出し先はスマホのスピーカーで、同伴者はここで空を見る。
  30 秒で消える既定のままだと、暗い屋外でロック解除を繰り返すことになる
- **戻るキーは 1 つ前の画面へ。** 既定のままだと戻るでアプリが終わる。
  設定パネルを開いていれば閉じるだけ、星図の画面では確認を挟む
  （**やめると方位合わせからやり直し**になるので、一度の誤操作で畳まない）。
  ホームでは受けない（**そこは終わってよい場所**）
- **回転で Activity を作り直さない。** ホーム・接続・星図は Compose の再構成だけで縦横を切り替え、
  グラスに置いたテキスト枠の記憶、BLE 購読、観測セッションを残す。方位合わせへ入ったときだけ
  縦画面へ固定し、抜けたら端末の回転設定へ戻す（顔の前にかざす操作でいちばん回りやすく、
  横持ちのセンサー軸を取り違えると方位が 90° ずれる）

## 待ち時間の見せ方

**このアプリは黙る場面が多い。** 画面が切り替わったのに何も出ないと壊れたと思われる（`ui/component/LoadingPanel.kt`）。

| 待つもの | かかる時間 | 出す場所 |
|---|---|---|
| 人工衛星の TLE（10,748 機） | 1〜2 秒 | 画面の先頭 |
| **1 枚目の転送** | **実測 332〜390ms＋描画待ち 200ms** | **プレビューの枠の中** |
| 転送中（2 枚目以降） | 同上 | プレビューに札を重ねる |

**転送中はグラスから絵が消える。** スマホのプレビューは前の絵のままなので、
食い違いを札で明示する（`送信中（グラスは一時的に消える）`）。

## 通知の入／切（流星群の予告・#70）

**いつ・何を出すかは [解説と声](34_narration.md)。** ここは入／切の口だけ。

- **既定は切ってある。** **ホームのトグルを入れたときに許可を聞く**（断られたらトグルを切に戻す）
- 入／切は **ホームと観測画面の設定パネルの 2 か所**。入れるのは出かける前、切りたくなるのはその場
- タップするとホームが開き、**ひとことがその流星群になる**
