# 実機確認の手順

**確かめていないことを「動く」と書かないための手順書。** 計算だけで確かめられることは JVM テストで
固定してあるので、ここに残っているのは**実機（BLE）と空が無いと確かめられないもの**だけ。

夜の屋外では画面を見ている余裕がないので、**数字はアプリが自分でログに残す**。
人がやるのは「動かす」ことと「合格しているか読む」ことだけ。

- 入れる: `cd samples/kmp && ./gradlew :app:installDebug`
- 取り出す: `tools/pull-session-log.sh`（`--logcat` で logcat も、`--clear` で仕切り直し）
- 仕様の背景: [座標変換](coordinate-system.md) / [見送った精度計画](alignment-accuracy.md)

## A. 机の上（5 分・BLE だけあればよい）

| # | やること | 合格 | だめなとき |
|---|---|---|---|
| A1 | アプリを起動して観測画面まで進む | グラスに星図が出る | ログの「失敗」行を読む |
| A2 | 設定パネルを開く | 6DoF が「受信中」 | `startImuData` が通っていない |
| A3 | スマホのケースの磁石かハサミを方位合わせ画面で近づける | **「磁石か鉄が近くにあります」の赤い警告が出る**（先へは進めたまま） | 磁力計が無い端末かもしれない |
| A4 | 磁石を離す | 警告が消える | しきい値が厳しすぎる（`MagneticQuality`） |

**机の上では A3 の警告が出っぱなしになるのが正常。** ノート PC・ディスプレイ・鉄の脚が
20〜30cm にあれば磁力計は振り切れる。**方位そのものを確かめられるのは屋外だけ**なので、
机では警告が出ていても先へ進んでよい。

## B. 昼にできること

**いまの main には無い。** 画角の実測・加速度軸の自動判定・ロール追従の符号確認は、
測るための UI ごと外してある（[見送った精度計画](alignment-accuracy.md) の E と C）。

実機で測った値そのものは捨てていないので、戻すときはここから始められる。

| 測ったもの | 結果（2026-08-21・Pixel 9a） |
|---|---|
| 加速度の軸 | **上=+X・前=−Y**。うなずきのジャイロと重力から解いて約 40 秒 |
| ロールの符号 | **正しい**（傾き 1.00→0.99→0.91・89 件） |
| 画角 | **測っていない。** `STAR_MAP_FOV_DEG = 35.0` は仮のまま |

## C. 夜の屋外（本番・30 分）

**明るさは屋外で決め直す。** 屋内で合わせた明るさは暗闇では確実に明るすぎる。

### C1. 方位合わせ（これだけ）

グラスの十字とスマホの中央を重ね、**そのまま止める**。**地平線から 45° くらい**を向く。

| 見るもの | 合格 |
|---|---|
| 確定 | **押さずに、止めて 2〜3 秒で観測画面へ進む**（確定のボタンは無い） |
| 手順の時間 | **15 秒以内**（説明なしで 3 人が完了できるか） |
| 進み具合 | **的の外周が緑で満ちていく**（崩れると 0 に戻る）。文字は直すことがあるときだけ出る |

- ここで残るのは**地磁気の誤差 ±5〜15°**。**星座の同定（±20°）はこれで成立する**。
  星図が空にぴったり重なることは狙っていない（[理由](alignment-accuracy.md)）
- **方位合わせは 1 回だけ。** ずれたと感じたら `HOLD` でここへ戻る

### C2. 星図が空に重なっているか

| 見るもの | 合格 |
|---|---|
| 明るい星の位置 | 視野中心で**ずれが分からない**程度 |
| 視野端 | **端はずれる。** 画角が仮の 35° で、ロールも追従していない |
| 首を止めてから | **0.3 秒ほどで 1 枚届く**（0.18 秒静止＋転送）。**動かしている間は前の絵のまま**が仕様 |
| 首を傾けたとき | **地平線が本物と同じだけ傾く。** 逆に回るなら `Astro.kt` の `ROLL_SIGN` を反転する |
| 画像の大きさ | 544×340 で出ているか。ログに「入らないので落とす」が出たら 528×330 に落ちている |
| 星座絵 | **輪郭で、なにの絵か分かるか。** 薄すぎて見えないなら `ART_VALUE` を 1 段上げる |
| 月・惑星 | **月は満ち欠けの形、惑星はアイコン**。名前が星座名より先に出る。天王星から先は**目では見えないが点は出る** |
| 一等星の名前 | ベガ・アルタイルなどが 2 つまで出る。**星座名を押し出していないか** |
| 月の欠け方 | **光っている側が実際の月と同じか。** 太陽の方向から計算している |

### C2.5 グラスが黙ったとき

**十字が出ず、6DoF も来ない**ときは、10 秒で「グラスから返事がありません」に変わる。

| 押すもの | 何をするか |
|---|---|
| 送り直す | `stopImuData` → 0.3 秒 → `startImuData` ＋ 十字を送り直す。**まずこちら** |
| グラスを再起動 | `dbg reboot`。つながり直すまで **30 秒ほど**かかる |

**アプリを入れ直す（＝プロセスを殺して BLE を張り直す）と直った実績がある**（2026-08-22）。
それでも直らないときだけ再起動を押す。

### C2.7 声で質問する（#38）

`HOLD` で始まる。**通信のある場所で試す。**

| 見るもの | 合格 |
|---|---|
| 反応 | ホールドした瞬間に「聞いています。質問をどうぞ。」が出る |
| 待ち | **読んでから話し出すまで 6 秒ある**（間に合わなければ「聞き取れませんでした」になる） |
| しきい値 | ログの `暗騒音○→しきい値○`。**風の夜は 900 より上がっているか**（上がらないなら暗騒音を測れていない） |
| 区切り | **黙ると 1.2 秒で止まる。** 12 秒フルで録り切るならしきい値が低すぎる |
| 聞き取り | 「〇〇座って何なの？」がそのまま字幕に出る |
| 答え | 2〜3 文。**見えていない天体の名前を出していないか** |
| 長い質問 | **12 秒喋って通信が遅くても、答えが字幕に出る**（途中で星図に戻らない） |
| 圏外 | 「いまは通信ができないので、質問には答えられません」と喋る（**黙らない**） |
| 方位合わせ | **ホールドでは方位合わせに行かない**（スマホのボタンへ移った） |

### C3. 星座の解説（#40）

`SINGLE_TAP` で開始。**機内モードでも同じ結果になること**を必ず 1 回試す。

| 見るもの | 合格 |
|---|---|
| 画面の切り替え | タップした瞬間に星図が消え、**見出し「〇〇座 南南西 45°」が出る** |
| 文字の量 | **1 行が切れていない。** 切れていたら `GlassTextPage.lineChars` を数えた値に直す |
| 本文 | **2 行ずつめくって最後まで出る。** 見出しと最初の行が消えていないか |
| めくる速さ | 読み上げと大きくずれていないか（1 文字 150ms・最短 2.6 秒） |
| めくり始め | **1 枚目は声が出てからめくる**（声より先に 2 枚目へ行かないか） |
| 戻り方 | ①もう一度タップ→止まって星図 ②放置→読み上げ終了 5 秒後 |
| 読んでいる間 | **首をどれだけ振っても戻らない**（首の向きでは戻さない） |
| 声 | **1 回の解説の中で声が入れ替わらない。** 入れ替わるならその星座を見ながら電波のある場所で 1 度出す |
| 月・惑星 | 視野にあれば「いま近くに木星が出ています」と足す |
| 声 | AI 音声。圏外やキー無しなら端末の読み上げに落ちる（**黙らない**） |
| **圏外** | **機内モードでも解説が最後まで出る**（文字は必ず出る。声だけ端末のものに変わる） |

### C4. 30 分そのまま観測する

- **合格 =** 空の見え方と星図が**同じ方角のまま**（首を振った分のドリフト漏れが溜まらないか）
- ログの「ドリフト監視」で、**補正後の方位が ±2°/分 以内**（生のヨーは −44°/分 が正常）
- 静止 4 分で 0.0°/分 になるのが理想（実測済みの値）

### C5. スマホ側で 1 回ずつ確かめる

観測を止めずに済むかどうか。**どれも「戻る」で観測が終わらないこと。**

| 見るもの | 合格 |
|---|---|
| 消灯 | **30 秒放置しても画面が消えない**（消えるなら `KeepScreenOn` が効いていない） |
| 回転 | 端末を横にしても**画面が回らない**（回ると観測がやり直しになる） |
| 戻るキー（設定中） | 設定パネルが閉じるだけ。観測は続く |
| 戻るキー（星図） | 「観測をやめますか」が出て、**「観測を続ける」で何も起きない** |
| 設定パネル | 見出しごとに分かれていて、**音と BGM がログの中に無い** |

## D. 帰ってきたら

```bash
tools/pull-session-log.sh
```

要約に出るのはこの 2 つ。**A・C で見た数字がそろっているか**を確認する。

| 項目 | 期待 |
|---|---|
| ドリフト補正 | 補正後 ±2°/分 以内 |
| 失敗した行 | **0 行**（あれば全部読む） |

**確かめた数字は [index.md](index.md) の表と各仕様書へ書き戻す。**
「実機確認待ち」を消すのは、ここを通したときだけ。
