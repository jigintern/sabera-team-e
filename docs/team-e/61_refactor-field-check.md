## ① 衛星の名前（#87）

- **直したバグが実機で直っているかを見る。** 「前と同じ」ではなく「前と違う」ことを確かめる
- [x] 設定パネルで衛星を出し、名前つきが 1 機でも視野に入る向きを探す
- [x] **首を左右に 15° ほど傾ける。** 名前が枠に付いてくるか（傾けると名前だけ消える・ずれるのが元の症状）
- [x] そのまま 2 秒ほど止める。1.5 秒ごとの印の更新で**名前がワープしない**か
- [x] **描かれていない衛星の名前が出ていないか。** 点も枠も無いところに名前だけ浮いていたら直っていない
- [x] 出る名前は 3 機まで。ISS・天宮・みちびき・GPS・ガリレオ・ひまわり・ハッブル以外が出ていないか

## ② 観測画面からの切り出し（#88）

- **判断のロジックを別ファイルへ移した。** 数値は同じなので、繋ぎ直したところが効いているかを見る

- [x] **描き直しの間隔が前と同じか**（0.18 秒静止＋6°）。首を小さく振っても描き直さず、6° 以上動かして止めると出る
- [x] 首を傾けたときに地平線が水平を保つか（傾き 5° で描き直し）
- [x] **先出しが効いているか。** 大きく振って止めたとき、止まる前に絵が出始める
- [x] 星座をタップして解説が出るか（**タップの反動で隣の星座に化けないか**＝視線ラッチ）
- [x] 設定パネルのログが 40 行で流れ、`tools/pull-session-log.sh` でファイルが取れるか
- [x] `adb logcat -s StarMap` が従来どおり出るか
- [x] 戻るキー：星図では確認ダイアログ、ガイド系ではガイド一覧、ホームでは終了

## ③ ViewModel 化（#89）

- **いちばん確認が要る。** ViewModel は Activity スコープで、`remember` と違って画面を抜けても消えない
- 「入り直したら真っさら」を `leave()` / `reset()` で再現しているので、**残ってはいけないものが残っていないか**を見る

- [x] 接続確認で失敗させ（グラスの電源を切って接続）、**ホームへ戻って入り直すとエラー表示が消えている**か
- [x] 方位合わせを済ませて星図へ入り、「方位を合わせ直す」でもう一度入る。**進み具合のゲージが 0 から始まる**か
- [x] 方位合わせが**二重に確定しない**か（1 回だけ星図へ進む）
- [x] グラスを黙らせて「送り直す」「再起動」を連打する。**同じ電文が並ばない**か、結果の文が出るか
- [x] ガイド一覧で台本を作り、**戻って入り直すと「作りました」の表示が消えている**か
- [x] ガイドの受け取りで QR を読み、中身を見せた状態で戻る。**入り直すと中身が残っていない**か
- [x] 詳細エディタで空に無い星座を頼む。**通信せずに断る**か（機内モードでも同じ文が出る）
- [x] 配る画面で段を外す→戻る→もう一度開く。**外した段が原本に残っている**か
- [x] 観測中に瞬断させて（グラスを離す→近づける）、**観測画面から追い出されない**か

## ④ 高速化（#90）

- **出力は変えていない**ので、見え方が前と同じであることを見る。速くなったかは体感で足りる

- [x] 星図の見え方が前と同じか（星の数・線・星座絵・月惑星の位置）
- [x] 衛星の点と名前が前と同じか（①と同時に見られる）
- [x] **解説の声が前と同じか。** 先読みの鍵を変えたので、圏外で端末の読み上げに落ちたときも声が入れ替わらないか
- [x] 流星群の日に放射点の印が出るか（出る日が限られるので、出せる日だけ）
- [x] 濃い空（設定パネルの「すべて」）で**バッファ超過が出ないか**
- [x] 案内中に濃い空で星図が出るか（矢印を外して星図を通す経路）
