## ヨードリフト補正の「ゆっくりした首振り」（見送り・2026-08-27）

**しきい値そのものは実機で測って決めた設計なので、実機で確かめるまで触らないことにした。**
先に[ロールの軸](72_pitfalls.md)を直したので、まずそちらの効果を C2 で読む。

`YawDriftCorrector` は「ジャイロの大きさ > 2°/秒」で動きを判定する。
**それ未満の首振りは星図に反映されないうえ、静止区間の標本としてドリフト推定に混ざる。**
実装をそのまま写して回した結果（ドリフト −0.74°/秒・首振り 6 種を 3 巡・間に 8 秒ずつ静止）:

| 止めている間の首の動き | 1 分ほど後のずれ | 推定ドリフト |
|---|---|---|
| 完全静止 | **+0.07°** | −0.74°/秒（正しい） |
| ±1°/秒 でゆらぐ（周期 4 秒） | −3.5° | −0.89°/秒 |
| **0.3°/秒 ずつ一方向に這う** | **−54°** | −1.19°/秒 |
| 1.5°/秒 ずつ一方向に這う | −251° | −2.24°/秒 |

- **ゆらぐだけなら打ち消す。** 効くのは**わずかでも一方向に這ったとき**で、
  推定が汚染されると以降の首振りが毎回過補正され、**動くほどずれが増える**
- [71_yaw-drift.md](71_yaw-drift.md) が測ったのは「静止中のノイズ 0.1°/秒」と
  「首振り 10〜100°/秒」で、**その中間（空を舐めるように見回す動き）は測られていない**
- 直すなら「**ジャイロが本当に回ったと言っている区間をドリフトの標本から外す**」が安全側
  （`gyroXDps` が鉛直軸であることは台帳に実測がある）。しきい値を下げる／静止中も積む案は
  実機で測り直しが要る

## 結果が変わる高速化（実装していない）

**出力不変のものだけ実施**と決めたので、下は測っただけで入れていない。
入れるなら「どこがどう変わるか」を先に決めること。

| 案 | 効果 | 代わりに変わること |
|---|---|---|
| `SatelliteScene` の `APPROACH_STEP_MIN` を 0.5 → 1.0 分 | 最接近を探す伝播が半減 | **最接近の表示が 1 分刻みになる** |
| `nextPasses` を粗く探してから絞る 2 段スキャン | パス探索が数倍速い | 境目の 1 分をまたぐと結果が変わりうる |
| 高度 10° 以上で屈折補正を省く | 座標変換 1 回ぶん | ずれ 0.1° 未満（**星座の同定 ±20° には効かない**） |
| `drawGreatCircle` を 3° → 5° 刻み | 線を引く回数が 6 割 | 長い線が多角形に見える |
| フレームの `ByteArray`（185KB）をダブルバッファ化 | 毎フレームの確保が消える | **`lastMap` が同じ配列を指すので、焼き直しと送信が噛み合うと絵が壊れる** |

## 手を付けていない範囲

| 範囲 | なぜ触っていないか |
|---|---|
| `ui/StarMapScreen.kt` 本体（約 90 の状態・3,000 行超） | 純ロジックは切り出して ViewModel とテストへ移したが、**画面そのものは残した**。残っているのは描画・フォーカス・入力の状態で、ViewModel へ移しても**間接層が増えるだけでテスト性は上がらない** |
| `CalibrationScreen` の 10Hz センサ値 | 同じ理由。角度の計算だけ `alignment/` へ出してテストしてある |

## 点検して問題なしだったもの

**「同じところを二度調べない」ためだけの節。** [72_pitfalls.md](72_pitfalls.md) の既知の落とし穴を、
2026-08-26 に全ファイルで点検した結果。

| 見たもの | 結果 |
|---|---|
| `optString` を JSON の null に使っていないか | 全箇所 `isNull` ガード済み |
| `coroutineScope { }` の中で `SupervisorJob` を作っていないか | ゼロ |
| `% 360.0` の負値の扱い | 全 20 箇所とも正しい（**`normalizeDeg` へ一括置換してはいけない**。折り返す範囲が違う） |
| 空リストへの `first()` / `single()` | すべてガード済み |
| 星座境界表に穴が無いか | 全 decLow 境界で赤経 0〜24h を覆っている（`ConstellationBoundaryCatalogTest` が検査） |
