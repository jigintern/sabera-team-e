# 画面遷移とジェスチャー

何を触ると何が起きるか、そのときグラスとスマホに何が出ているか。
何を喋るかは [解説と声](06_narration.md)、出力の制約は [グラス出力の制約](02_glass-output.md)、
座標変換は [座標変換パイプライン](03_coordinate-system.md)。
## 役割分担

**操作系はグラスで完結させる。スマホは見なくても使える。**

| | 役割 |
|---|---|
| **グラス** | 星図と星座名を出す。ジェスチャーで操作を受ける |
| **スマホ** | 計算する。音声を鳴らす。**同伴者に見せる**。詰まったときの整備画面 |

- グラスをかけている人は空を見ていて**スマホは見ない**
- 星を見に行くのは複数人のことが多く、**グラスは 1 人しかかけられない**ので、
  スマホ画面は同伴者のためにある
- **例外は初回の接続だけ。** `showAutomaticSelectionDialog(activity)` が Activity を要求するが、
  `connectToLastDevice()` を呼んでおけば 2 回目以降は自動接続になる
  （初回かどうかは `hasLastConnectedDevice` で分岐できる）

## ジェスチャー

使えるのは 3 つだけ。**3 枠はすべて埋まっている。**

| ジェスチャー | 割り当て | 挙動 |
|---|---|---|
| `SINGLE_TAP` | **送信／解説の開始・停止** | 録音中は質問を送信。案内中は案内だけを終了。それ以外は解説画面へ入り、もう一度で止めて星図へ戻る |
| `DOUBLE_TAP` | **一口メモ** | いまの時刻と場所から言えることを 1 つ。**押すたびに次のメモへ進む** |
| `HOLD` | **声で質問・天体を指定**（#38・#46） | 案内中なら先に終了。録音を始め、`SINGLE_TAP` で送信後、質問へ回答または案内を開始 |

**ガイド中だけ意味を入れ替える**（[星座ガイド](16_guide.md)）。終わると元へ戻る。

| ジェスチャー | ガイド中 |
|---|---|
| `SINGLE_TAP` | **次の段へ**（録音中の送信だけは入れ替えない） |
| `DOUBLE_TAP` | **いまの段をもう一度** |
| `HOLD` | **据え置き。** ガイド中に浮かんだ疑問こそ聞きたい |

- **枠は増やしていない。** やめる口はスマホに置く（上部バーと設定パネル）。
  グラス側に「やめる」を足すと、**次へ送るつもりの 1 回でツアーが終わる**
- **ガイド中は案内のラベルに方角を足す**（`さそり座 南南西 高いところ`）。**枠は 1 つのまま**で、
  到着すると `さそり座 このあたり` に変わる。声で頼んだ案内（#46）は `さそり座 案内中` のまま。
  **騒がしい場所では文字が主役**なので、向く先を声だけに置かない
- **解説はワンタップと同じ解説専用画面へ流し、流し終わるまで次の段へ進まない**
  （[星座ガイド](16_guide.md)）

**ジェスチャーのほかに、解説画面だけで首の上下フリックを取る**（うなずいてすぐ戻す動き）。

| 入力 | どこで | 何をするか |
|---|---|---|
| 上へフリック | **解説画面だけ** | 字幕を 1 行**戻す**（上の行へ） |
| 下へフリック | **解説画面だけ** | 字幕を 1 行**送る**（下の行へ） |

- **「あれは何？」は視線の向きで完全に決まる**ので、**タップそのものが質問になっている**。
  最初の一言に音声入力は要らない
- **方位合わせは `HOLD` から外してスマホのボタンだけにした**（#38 に枠を渡した）。
  合わせ直しは急がないので、スマホを見られる場面で押せば足りる
- **ホールドしている間だけ録音することはできない。** SDK 0.6.0 は `HOLD` の1イベントだけで、
  押下開始と指を離した時刻を返さない。現在は **`HOLD` で録音を始め、`SINGLE_TAP` で送信**する
- **解説画面から星図へ戻すのは 2 つだけ**（#40）。**タップ**＝止めて戻る、
  **読み上げ終了の 5 秒後**に自動。枠は増やしていない
- **首の向きでは戻さない。** 一度は「首を振ったら空を見たいということ」として入れたが、
  **解説を読んでいる途中で見上げただけで消えた**。読み終わらないまま星図に戻るほうが困る
- **首を使うのは解説画面の字幕送りだけ**（`alignment/HeadFlick.kt`）。星図を出している間は
  **頭の向き＝見ている空**なので、命令に使うと**命令のたびに見る空が変わる**。
  そのうえ速い首振りは方位補正がいちばん苦手なところ（10Hz の取りこぼしで 90° あたり 5〜15° 足りない）。
  **解説画面は首が視線ポインタになっていない唯一の状態**なので、ここだけ許す
- **向きではなく「振って戻る」形で見分ける。** ゆっくり見上げたときは基準が付いていくので
  反応せず、**速く振って元へ戻ったときだけ**発火する。戻りを待つぶん 0.1〜0.5 秒遅れるが、
  **その戻りこそが「操作のつもり」の証拠**なので削れない（削ると上の失敗をなぞる）
- **読み逃したら戻せる。** 字幕は 2.6〜3.6 秒で流れていくので、いちばん多い困りごとが
  「読み切る前に流れた」になる。**タップは「もう終わり」**なので、押すと止まって星図へ戻ってしまい、
  読み直す手立てが無かった。**最後の 1 枚は流れ切ったあとも数秒置いて、そこからでも戻せる**
- 自動で戻す時計の**起点はタップではなく読み上げの終わり**（合成が遅れると読む前に消える）。
  音が鳴らなかったときは 25 秒待つ（**騒がしい場所では文字が主役**なので、読み終わる前に消さない）
- **`DOUBLE_TAP` は一口メモに付け替えた。** 衛星の重ね切り替えは**スマホの設定パネルだけ**に戻した。
  空を見ている人が押して意味があるのは「いまここで何が言えるか」で、重ねの切り替えは
  スマホを見られる場面で足りる
- **一口メモの中身と順番は [解説と声](06_narration.md) にある**（`narration/SkyTips.kt`）。
  通信も生成も要らず、**押すたびに次のメモへ進む**（1 つしか言わないと、2 回目が無反応と区別できない）
- `gestureEvents` は `SharedFlow` なので、**購読前のジェスチャーは受け取れない**。
  接続完了 → 購読開始 → 「準備できました」の順を守る
- **リモコンのイベントは 0.5.0 で撤去された**ので拾えない

## グラスに何を出すか

**キャンバス（576×360）に星図画像を置き、その手前に星座名を重ねる。**

```
┌─────────────────────────── 576 ───────────────────────────┐
│   おとめ座                        しし座                    │  ← テキスト（8 要素・190B）
│         ·      ·                                           │
│      ·      ·        ·                                  360│
│         ·         ·                                        │  ← 画像（528×330 まで）
│              ·                                             │
└────────────────────────────────────────────────────────────┘
```

| 出すもの | API | 更新 |
|---|---|---|
| 星図 | `sendCanvasImage`（id 固定の 1 枚） | 首が止まってから。実測 332〜390ms＋描画待ち 200ms |
| 星座名 | `sendCanvasElements`（差分更新） | 毎フレーム。数十 ms |
| 月・惑星の名前 | 同じテキスト枠。**星座名より先に置く**（月と 8 惑星） | 画像と一緒 |
| 大三角の名前 | 同じテキスト枠を **1 つだけ**借りる | 画像と一緒 |
| 一等星の固有名 | 同じテキスト枠を **2 つまで**借りる。全天に 21 個しかなく視野には 1 つあるかないか | 画像と一緒 |
| 地平線・方位の文字 | **画像に焼く**（テキスト枠を使わない） | 画像と一緒 |
| 流星群の放射点 | **画像に焼く。** 中心を空けた放射状の線で「ここから広がる」を形で読ませる。**名前は出さない**（一口メモが喋る） | 画像と一緒 |
| 月の満ち欠け | 画像に焼く。**太陽のある側が光る**ので、太陽の方向を投影して向きを決める | 画像と一緒 |

**つないだ直後からグラスに出す。** ホームと接続確認の間、グラスは真っ暗だった。

```
┌──────────────── 576 ────────────────┐
│                                      │
│       [ 採用ロゴ：星しるべ ]           │ ← 幅 288px
│                                      │
│   今夜は上弦の月で、新月から数えて7日目。 │ ← 24px・中央揃え
│   光と影の境目では、クレーターの影が     │
│   いちばん長く伸びて見えます。          │
└──────────────────────────────────────┘
```

- **これはテキスト枠では作れない。** 要素にあるのは座標と大きさと文字だけで、
  **専用字形もフォントの指定も扱えない**。透過ロゴと本文を **画像に焼く**
  （`drawable-nodpi/hoshishirube_logo.png` / `glass/GlassTextArt.kt`）
- スマホ用のミント色はグレースケールにすると文字より暗くなるため、**グラスへ描くときだけ
  ロゴ全体を白へ変換する**。スマホ側の配色は変えない
- **動かないので 1 枚送って置いておくだけ。** 1 枚 332〜390ms かかるが、
  挨拶なら気にならない（**回るものは画像でやらない**）
- **本文は入る大きさまで自動で落とす**（30 → 20px）。ひとことの長さはメモによって
  倍近く変わるので、固定にすると溢れるか間延びする。**いちばん長い 113 文字でも 24px で 7 行**
- **キリのいいところで改行する。** 幅だけで切ると文の途中で行が変わって読みにくい。
  行が埋まったら**句読点まで戻れるなら戻って切る**（戻りすぎて行がすかすかにならないよう、
  行の 55% より後ろの句読点だけを使う）。行頭に置けない字は前の行へ吸わせる
- **テキスト枠を先に掃除してから画像を出す。** ファームは消すまで文字を持ち続けるので、
  前に動いていたときの星座名が残っていると**画像に重なって出る**（実機で踏んだ）
- **起動ごとに違うひとことから始める。** 毎回同じ文だと、出ていること自体に気づかなくなる
- **次の画面へ渡す前に消す。** 方位合わせは別の id（十字）を送るので、
  残すと十字の裏に挨拶が残ったままになる
- 観測地は既定値（まだ測位していない）。**場所で変わるメモは少しずれる**が、ここは挨拶なので追わない
- 材料づくりは `narration/TonightSky.kt` に 1 か所だけ置く。**星表を待たずに作れる**
  （時刻と場所の計算と、2KB の流星群だけ）

**読み込み中もグラスに出す。** 星表を読み終わるまで、グラスは真っ暗だった。

```
┌──────────── 576 ────────────┐
│ ／ 星表を読んでいます          │ ← 5 コマ／秒で回る
│ 頭の上で明るい三つ、こと座の    │ ← 今日のひとこと（3 秒ごとに 2 行）
│ ベガ、わし座のアルタイル、     │
└─────────────────────────────┘
```

- **クルクルはテキスト枠で回す。画像では成立しない。** 全画面の画像は 1 枚 332〜390ms で、
  **転送中は前の絵が消える**ので点滅にしかならない。テキストなら 1 要素 15 バイト・1 電文で
  **実測 8〜9ms**。全角 1 文字で幅が変わらないので、**前の矩形を覆って消し残らない**
- **画像を使わないので、キャンバス画像が動かないファームでも出せる**
- **「読み込み中」ではなく何を読んでいるかを書く。** 待つ理由が分かる
- **待ち時間が短ければ何も出さない**（0.4 秒の猶予）。同梱データはアプリの生きている間
  1 回しか読まないので、2 回目以降の観測画面はここで抜ける。
  **映って消えるだけの画面はちらつきにしかならない**
- **失敗したらクルクルを止めて理由を出す。** 回り続ける画面は、固まったのと区別が付かない
- **待つのは星図が描けるようになるまで。** 軌道要素（10,748 機）がいちばん重いが、
  衛星は星座のおまけ（#36）なので、そちらを待って星図を出し遅らせない
- ひとことは一口メモ（`SkyTips`）と同じものを使う。**星表を待たずに作れる**
  （中身は時刻と場所の計算だけ）。ここで 1 つ使うので、**最初のダブルタップでは次のメモが出る**

**解説文もグラスに出す**（#40）。ただし**星図とは同居させず、専用ページに切り替える**。
以前は「190 バイトでは入らない」として出さない決定だったが、星図を消せば置く先ができる。

```
1 枚目                              2 枚目から
┌───────── 576 ─────────┐          ┌───────── 576 ─────────┐
│ おとめ座 南南西 45°   │ ← 見出し │ 麦の穂を手にした、農業 │ ← 見出しは畳む
│ 麦の穂を手にした、農業 │          │ の女神の姿です。春の空 │
│ の女神の姿です。春の空 │          │ でいちばん大きな星座で │ ← 1 行ずつ上へ「流す」
└───────────────────────┘          └───────────────────────┘
```

**1 枚に何行・1 行に何文字入るかは [グラス出力の制約](02_glass-output.md)。** ここは見せ方だけ。

| | 値 |
|---|---|
| 流す速さ | 新しく出た文字 × 150ms・最短 1.6 秒（読み上げはおよそ 7 文字／秒） |
| 遅くする | **1 行流すごとに 6% ずつ延ばし、1.4 倍で頭打ち**。**実機未確認** |
| 上限 | **16 行（272 文字）**。解説文はこの中に収めてある |

- **送るのは 1 行ずつ。** まとめて入れ替えると全部の行が新しくなり、どこから読めばよいかが
  毎回分からなくなる。1 行ずつ上へ流せば、**下にあった行がそのまま上へ来る**ので、
  読みかけの行を目で追い続けられる（送る回数が増えるだけで、1 電文という制約は変わらない）
- **1 枚目は音が出るまで置いておく。** 合成に 1〜2 秒かかるので、先に流し始めると
  **字幕が声より先へ行く**
- **後ろの行ほどゆっくり流す。** 読み上げは文の切れ目で息が入るのに、字幕は 1 文字あたり
  一定で数えているので、**流すほど字幕が声より先へ出ていく**。頭打ちを置くのは、
  **声が終わったあと字幕だけが延々と残らない**ようにするため
- **流し終わるまで星図へ戻さない。** 読み上げが先に終わっても、字幕が残っていれば待つ
- **声で質問している間は見出しを出さない**（#38）。星座名と方角が上に出ていると、
  聞いたことと関係のない星座について答えているように見える。**AI へ渡す事実には星座が入っている**
- 解説の短い見出しには**星の点（`●`）**を添え、本文3行の静かな字幕と役割を分ける。
  長い星座名＋方角は切らず、点を付けない
- **質問を待つ間は「質問をどうぞ。」＋拾っている音の星**（`●○`）＋**「タップで送信」**を出す。
  文字起こしは録り終わってから 1 回なので、喋っている最中に返せるのは音の大きさだけ。
  **星が点灯していれば声として拾えている**。表示の送り直しは 0.4 秒おき
  （マイクが毎秒 32,000 バイトを同じ BLE に流しているため）
- **視野中心の十字はやめた。** 星見アプリはどれも出しておらず、解説画面が主役の星座を
  名前で出すようになったので、いちばん価値のある画面中央の画素を空けた

## 画面遷移

![画面遷移](diagrams/screen-flow.drawio.svg)

- **キャンバス 1 枚で回る。** ページ遷移が要らないので、状態はほぼ「観測中かどうか」だけ
- **方位合わせ中は星図を消して十字だけを出す**（バッファに同時に入らない）
- **十字は 6DoF が来るまで送り直す。** 観測画面から「方位を合わせ直す」で来ると、
  **あちらの後片付け（`stopImuData` と `closeCanvas`）がこちらの描画より後に走る**ことがあり、
  送ったばかりの十字が消えて 6DoF まで止まる（2026-08-22 実機）
- **「つながっているのに返事が無い」を出せるようにする。** BLE がつながっていれば
  `connected` は true のままなので切断ダイアログは出ない。実機では、グラスが再起動したあと
  6DoF も画像も一切返さないまま「6DoFを待っています」が出続けた（2026-08-22）。
  **10 秒たっても 6DoF が 1 件も来なければ**「グラスから返事がありません」に変え、
  **送り直す／グラスを再起動**を出す。**このグラスに電源ボタンは無い**ので、
  電源を入れ直す手段は `GlassClient.reboot()`（デバッグシェルの `dbg reboot`）しかない
- **解説中はグラスが解説画面に切り替わる**（#40）。星図の画像を消して文字だけにする。
  戻るときは星図を 1 枚送り直すので、**332〜390ms は暗いまま**

## 天体の案内（#46・#61）

| 段階 | グラス | スマホ・音 |
|---|---|---|
| 復唱 | 解説画面で「〇〇を案内します」 | 同じ文を読み上げ、約1秒置く |
| 左右を合わせる | 星図＋中央の塗った左／右矢印＋対象名＋**「左へ 32°」** | 「まず左／右を向いてください」＋角距離＋終了ボタン |
| 上下を合わせる | 星図＋中央の塗った上／下矢印＋対象名＋**「上へ 11°」** | 「次に上／下を向いてください」＋角距離＋終了ボタン |
| 10°以内 | 短い矢印（**細くはならない**） | 「もう少し」 |
| 5°以内を0.5秒 | 中央の星＋二重リング、対象全体を強調、「このあたり」 | 「〇〇はこのあたりです」 |
| 到着後 | 3秒置いて通常の星図へ戻る | 一時カードを消す |

- **対象は1つだけ。** 複数名を聞いたら選ばず、1つに絞るよう返す
- **斜めを一度に追わせない。** 左右差5°以内で上下へ進み、上下の途中で左右差が8°を超えたら
  左右へ戻す。ここでいう左右は方位で、首を傾けるロールではない
- **場所・方角・案内を明示したときだけ案内する。** 特徴・神話・「〜について」は解説へ回す。
  対象名だけ、または案内と解説を同時に頼まれたときは、どちらか聞き返す
- 案内中の `SINGLE_TAP` またはスマホの「案内を終了」で止める。`HOLD` は今の案内を止めて新しい音声入力へ進み、その次の `SINGLE_TAP` は送信になる
- 5°から外れても8°以内なら到着表示を保つ。8°を超えたら方向表示へ戻る
- 60秒で見つからなければ終了する。地平線の下は開始せず、**対象名と理由をグラスへ表示して読み上げる**。低空・明るい空は注意してから案内する
- **検索・履歴・対象一覧はスマホに置かない。** 案内中だけ一時カードを出し、設定とは混ぜない

## スマホの画面

**ホーム → 接続 → 方位合わせ → 星図**の 4 画面と、ホームから開く**ガイド作成**。星図の画面が本体で、
**上部バーの「設定」で設定と記録を別ページに畳む**。衛星の重ねはスマホの設定だけにある
（空を見ている人はスマホを見ないので、上のバーに常設しない）。
**解説または案内中だけ終了ボタンがバーに出る**（設定を開いていても止められる）。

```
┌─────────────────────────────┐
│ 現在の星空  [解説を止める][設定]│  ← 「解説を止める」は喋っている間だけ
├─────────────────────────────┤
│  グラスに表示している星空      │
│  ┌───────────────────────┐  │  ← 送った画像そのもの（緑 8 階調に寄せた色）
│  │        · ·  ·         │  │     名前はグラス側が描くのでここには出ない
│  └───────────────────────┘  │     出す前は「何を待っているか」を回して出す
│  グラスの向きを止めると更新    │
├─────────────────────────────┤
│ 星座解説                     │
│ さそり座                     │
│ 狩人オリオンを刺した、さそり…  │
├─────────────────────────────┤
│  [ この星空を解説する ]       │
│  [ ガイドを始める ]           │  ← 台本があるときだけ
│  [ 方位を合わせ直す ]         │
└─────────────────────────────┘
```

| 要素 | 中身 |
|---|---|
| プレビュー | グラスに送った画像そのもの。**同伴者に見せる用途にもなる** |
| 待ちの表示 | 星表・TLE・測位・転送。**何を待っているかを書く** |
| 案内カード | 案内中だけ、対象名・「まず左右／次に上下」・角距離・「もう少し」・終了ボタン。プレビューにもグラスと**同じ形・同じ大きさ**で矢印と到着リングを重ねる（**プレビューだけ見やすくしない**） |
| 解説 | 進み具合と本文。**タップはグラス側なので出力専用** |
| 今夜見た星座 | 解説した星座と本文。**もう一度**で読み直す（声も鳴らし直す）。1 つも無ければ出さない |
| ガイド | **「ガイドを始める」から台本を選ぶ**（ダイアログ）。流れている間は進み具合と「次へ／もう一度」（[guide](16_guide.md)） |
| 設定ページ | **使う機能だけ**を見出しごとの区画で置く。プレビュー → 今夜見た星座 → **声で聞いたこと** → 見え方（空の濃さ・星座絵・目印・人工衛星）→ グラスの明るさ → 音（声・読み上げ音量・BGM）→ 観測の状態（6DoF・方位合わせ・観測地）→ 記録 |

明るさは手動5段階のスライダーだけを置く。SDKから現在値を読み戻せないため、表示するのは
**このアプリが最後に送った値**。段階が変わると自動調整を無効化して値を送り、直前の星図を
再送して見た目へ反映する。ドラッグ中の値をすべて転送キューへ積まないよう、最新値だけをまとめる。

- **ガイドの台本を作るのはホームから**（`ui/GuideScreen.kt`）。**グラスが要らない**ので、
  出かける前に用意できる
- **始めるのは畳んだ側のボタンから。** 設定パネルの中に置いていたときは、
  「設定」を押し、区画まで送って「始める」を押す**3 手**だった。空の下で押すものは、
  **開いている画面のまま押せる**ところに置く。**始める口はここ 1 つだけ**にする
- **ボタンではなくダイアログで選ばせる。** 台本が増えてもメイン画面は太らない
  （押すものは常に「ガイドを始める」の 1 つ）
- **台本が 1 本も無いときはボタンを出さない。** 押しても何も選べないボタンは置かない
- **止める口を 2 つ並べない。** ガイド中は主ボタンが「ガイドを止める」に変わるので、
  進み具合のカードには「次へ」「もう一度」だけを置く（送るつもりで止めてしまう）
- **解説のカードはボタンの上**（音声が使えない環境ではテキストが主役になる）
- **見出しの中身を見出しどおりにする。** 以前は「ログ」という 1 枚のカードの中に
  星座絵・目印・声・BGM・音量まで入っていた。**BGM を切りたい人はログを開かない**ので、
  触れるはずの設定に辿り着けなかった
- **観測中はスマホを消灯させない。** 音の出し先はスマホのスピーカーで、同伴者はここで空を見る。
  30 秒で消える既定のままだと、暗い屋外でロック解除を繰り返すことになる
- **戻るキーは 1 つ前の画面へ。** 既定のままだと戻るでアプリが終わる。
  設定パネルを開いていれば閉じるだけ、星図の画面では確認を挟む
  （**やめると方位合わせからやり直し**になるので、一度の誤操作で畳まない）。
  ホームでは受けない（**そこは終わってよい場所**）
- **画面は縦固定。** 回転で Activity が作り直されると、グラスに置いたテキスト枠の記憶が消えて
  実物のラベルだけが残る。方位合わせは顔の前にスマホをかざす操作なので、いちばん回りやすい
- **平常時の上のバーに置くのは「設定」だけ。** 衛星の切り替えは設定に置く。
  解説・案内中だけ終了ボタンを一時的に足す
- **眺めるだけの情報は設定ページに置かない。** 空の状態・月齢・空にいる衛星の一覧・
  これから来るパスは、**触れない行**として並ぶだけで、触るはずの設定を下へ流していた。
  空を見ている人はスマホを見ないし、同伴者も操作に使わない行は読み飛ばす
- **位置と時刻を出すのは、間違っていても星図が「それらしく」出てしまうから。**
  タイムゾーンの取り違えは 135°、時計の 1 時間ずれは 15°。
  どちらもユーザーには気づけず、「AI が間違っている」と誤解される

### 待ち時間の見せ方

**このアプリは黙る場面が多い。** 画面が切り替わったのに何も出ないと壊れたと思われる（`ui/component/LoadingPanel.kt`）。

| 待つもの | かかる時間 | 出す場所 |
|---|---|---|
| 人工衛星の TLE（10,748 機） | 1〜2 秒 | 画面の先頭 |
| **1 枚目の転送** | **実測 332〜390ms＋描画待ち 200ms** | **プレビューの枠の中** |
| 転送中（2 枚目以降） | 同上 | プレビューに札を重ねる |

**転送中はグラスから絵が消える。** スマホのプレビューは前の絵のままなので、
食い違いを札で明示する（`送信中（グラスは一時的に消える）`）。
