# 星空の再現（#45）

**「いつ・どこの空か」を差し替える仕組み。** 何を再現でき、何を再現できないかをここに置く。
声の言い回しは [narration](06_narration.md)、画面の出方は [app-flow](05_app-flow.md)、
座標の理屈は [coordinate-system](03_coordinate-system.md)。

## 何を再現するか

| | できること | 出どころ |
|---|---|---|
| 場所 | 同梱 **18 都市**から選ぶ | `sky/CityCatalog.kt` |
| 日時 | 年月日と時刻。**都市のタイムゾーンで解釈する** | `sky/SkyCommand.kt` |
| 時間再生 | **実時間 2 秒ごとに 10 分**進め、**30 秒で自動停止** | `sky/ObservationMode.kt` |
| 戻る | 現在地・現在時刻へ戻す | 同上 |

- **任意の地名検索はしない。** 通信と曖昧さを持ち込むうえ、**星を見に行く場所ほど電波が届かない**。
  聞き取った文字から座標を推測もしない（別名も `CityCatalog` に閉じる）
- 時間再生は**観測条件とは別の状態**で持つ（`TimePlaybackState`）。
  混ぜると「場所を変えたら再生が止まる」「再生を止めたら場所が戻る」が起きる

## 決めたこと

| 決めたこと | なぜ |
|---|---|
| **声で言えるのは 4 操作だけ**（再現・再生・停止・現在へ戻る） | AI へ操作の可否を委ねない。#38 と同じ理由で、**喋るだけで設定を書き換えられる状態を作らない** |
| **判定は再現 → 案内 → 質問の順** | 「シドニーの夜空を**見せて**」の「見せて」は `GuidanceRequestParser` の案内語。逆順だと「その名前の天体は案内対象に見つかりませんでした」で潰れる |
| **確認文を見せてから適用する** | 聞き間違いのまま星図だけ変わると、**利用者は自分が何を見ているか分からない**。確認文の転送完了後 1.5 秒置く |
| **再現中はラベルを常時出す**（`LabelKind.STATUS`） | これが消えると、**作った空を本物と信じたまま実際の空を探す**ことになる。だからテキスト枠の**いちばん先**に置く |
| **再現中は時刻を止める** | 「20 時 30 分の空」は静止していてよい。動かすのは「再生」と明示したときだけ |
| **再現中に測位で上書きしない** | 「現在地を取り直す」を押しても、再現中の場所は変わらない |
| **TLE 元期から 7 日を超えたら衛星を出さない** | 軌道要素は数日しか持たない。**もっともらしい嘘の衛星を描かない**（理由はスマホに出す） |
| **夏時間の穴と重なりは勝手に埋めない** | 存在しない時刻・二通りある時刻は断って言い直してもらう |

## 時計の仕分け（いちばん危ないところ）

`System.currentTimeMillis()` は [StarMapScreen.kt](../../samples/kmp/app/src/main/kotlin/jp/jig/glasses/sample/kmp/ui/StarMapScreen.kt)
に 30 か所以上ある。**一括で差し替えると壊れる。**

| | 使うもの | 例 |
|---|---|---|
| **差し替える** | 空を計算するために渡す時刻 | 星・月惑星・衛星の位置、太陽高度（空の濃さ）、案内対象の算出 |
| **実時間のまま** | 計測・間隔・記録 | 転送の所要時間、静止判定（`STILL_MS`）、ラッチ（`LATCH_MS`）、ループ間隔、`NightRecord` / `AskHistory` の時刻 |

- 1 回の描画・解説は `ObservationSnapshot` を**組で持ち回る**。
  途中で引き直すと、**星・ラベル・喋る内容が別の瞬間の空になる**（#37 と同じ壊れ方）
- **AI へ渡す事実も再現時刻にする。** `AskFacts.localTime` を実時間のままにすると、
  グラスはシドニーの空を出しているのに **AI は今の鯖江の空の話をする**

## 深い時代（1 万年前・未来）— **未実装**

いまの範囲は **1900〜2100 年**。それを超えると断る。広げるには 3 つ要る。

| | 何が足りないか | 数字 |
|---|---|---|
| **長期歳差** | `precess()` は IAU 1976 の 3 次式で、**数世紀ぶんしか合わない** | T = 100 世紀だと `theta` の 3 次項だけで **−41,833″（−11.6°）**。式が発散する |
| **固有運動** | `data/stars.json` の列が `[hip, ra, dec, mag]` だけで**持っていない** | アークトゥルスは **2.28″/年 ＝ 1 万年で約 6°**。**星座の形が変わることこそ見どころ**なのに出ない |
| **星座線の張り替え** | `Constellation.lines` は**固定の赤経赤緯の折れ線**。星は動くのに線は動かない | 1 万年前で線が星から 6° 外れる。`Asterism` は HIP で持っているので影響なし |

- 長期歳差は **Vondrák, Capitaine & Wallace (2011)** が定番（±200,000 年で分角）。
  範囲で切り替え、近い時代は既存の式のまま使う
- 固有運動は**線形外挿**。視線速度による見かけの変化を無視するので、**近い星ほど誤差が出る**
- **月・惑星は範囲を超えたら描かない。** `sky/Ephemeris.kt` の近似は数世紀ぶんしか持たない。
  衛星と同じで、**もっともらしい嘘を描かずに理由を出す**
- 星座絵は外接矩形へ写すだけなので、線が動けば付いてくる

## 未決定事項

**勝手に埋めない。** 決めたら [00_index.md](00_index.md) にも反映する。

- **年だけ指定して昼になったとき**どうするか（「1 万年前」→ いまの時分が昼）。
  そのまま昼の空を出して「昼なので星が見えません。夜にしますか？」と聞き返す案が有力
- **足りない条件を聞き返すか、断るか。** issue #45 は「いつ頃の夜空でしょうか？」と
  **聞き返す**ことを求めているが、いまは `Rejected` で断って終わっている。
  聞き返すには**次の `HOLD` と合流する保留状態**が要る
- **一口メモ・流星群・今夜見た星座を再現時刻に合わせるか**（いまは実時間のまま）
- **時間再生の 2 秒間隔が屋外で点滅に見えないか**（[field-check](13_field-check.md) C2.10）
- **再現中の案内（#46）を許すか。** 空が止まっているので矢印は成立する
