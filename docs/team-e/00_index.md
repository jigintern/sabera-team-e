## 決まったこと

- 実機で動かして確定したもの。理由は右のリンク先にある

| 論点 | 決定 | 詳細 |
|---|---|---|
| 星図の出し先と大きさ | キャンバスに **528×330**。等級は「明るさ ＋ 点の大きさ」で表し、**点は丸く打つ** | [glass-output](11_glass-output.md) |
| 星座名 | 画像に焼かず**キャンバスのテキストで重ねる**。**画像を送ってから名前を送る** | [glass-output](11_glass-output.md) |
| 描き直しの条件 | **首が止まってから送る**（0.18 秒静止 ＋ 6° 以上）。減速に入ったら「止まる先」へ 1 枚 | [glass-output](11_glass-output.md) |
| 姿勢と方位 | 相対値はグラス、絶対方位の基準はスマホ。**十字とマーカーを重ねてもらう** | [coordinate-system](20_coordinate-system.md) |
| 精度と UX | **方位合わせは最初の 1 回だけ。±20°（星座の同定）で足りる** | [alignment-accuracy](74_alignment-accuracy.md) |
| 確定操作 | **押させない。** 精度条件が 2 秒続いたら自動で進む（**押す動作が頭とスマホを動かす**） | [coordinate-system](20_coordinate-system.md) |
| 観測地 | スマホの測位（融合 → GPS → 基地局）。取れないときだけ手入力 | [coordinate-system](20_coordinate-system.md) |
| シミュレーション | 主要18都市＋IANAタイムゾーンを同梱し、場所・時刻を全計算で共有。場所と日時は星図から消さない | [sky-simulation](38_sky-simulation.md) |
| **時間の連続再生はやらない** | 2 秒ごとに全画面を焼き直すと**転送のたびにパネルが消えて点滅する**。時刻は**つまみ**で動かす（離したときに 1 回だけ送る） | [sky-simulation](38_sky-simulation.md) |
| パーミッション | `ACCESS_FINE_LOCATION` ＋ `ACCESS_COARSE_LOCATION` を起動時にまとめて聞く | — |
| 星表 | 自前計算。データは同梱の `data/`（d3-celestial / XHIP。帰属は `NOTICE`） | [coordinate-system](20_coordinate-system.md) |
| 星座判定 | 解説の主役は**グラスに出したラベルの先頭**。IAU 境界表は代用に格下げ | [narration](34_narration.md) |
| **アプリ名は「星導」**（2026-08-26） | ランチャー・グラスの起動画面・星図のバーで共用する。**画面に名前を文字で出すのはグラスの起動画面だけ**（スマホは印と題で足りる） | [glass-screens](32_glass-screens.md) |
| スマホ側 UI | ホーム → 接続 → 方位合わせ → 星図の 4 画面＋ホームから開くガイド 4 画面。設定は**使う機能だけ** | [phone-ui](33_phone-ui.md) |
| 星座の解説 | `DOUBLE_TAP` で開始、`SINGLE_TAP` で終了。**同梱の解説文**を読み上げ、解説専用画面へ出す（#40） | [narration](34_narration.md) |
| **解説画面に星座絵を出す**（#127） | **星座絵だけ**を**本文 3 行の下の空き**（360×212）へ収めて 1 枚。**文字と重ねない**（3bit 8 階調では字か絵のどちらかが読めなくなる）。**見出しを出したあとに 1 回だけ送る**（流している間は触らない）。**実機未確認** | [glass-screens](32_glass-screens.md) |
| 読み上げの声 | **`gpt-4o-mini-tts` / `alloy`**。圏外・キー未設定・失敗時は端末の `TextToSpeech` | [sound](35_sound.md) |
| 音の鳴らし先 | **スマホのスピーカー**（グラスにスピーカーが無い） | [sdk](10_sdk.md) |
| BGM | 解説していない間も鳴らし、**太陽高度**で薄暮／夜を切り替え、解説中は 28% に絞る | [sound](35_sound.md) |
| **BGM は星図以外でも鳴らす**（#69） | **場面（薄暮・夜・ガイド）と曲を分ける。** 星図以外の画面は星図と同じ束を共用し、専用曲は**ガイド再生中だけ**。曲は 120 秒ごとにクロスフェードで渡り歩き、設定パネルで指名もできる | [sound](35_sound.md) |
| 声の送信 | **`HOLD` で録音開始、もう一度の `HOLD` で送信**。押し忘れは 30 秒で安全終了 | [narration](34_narration.md) |
| 画面の向き | ホーム・接続・星図・ガイドは**縦横に対応**（回転は Activity を作り直さず再構成だけで受ける）。横のホームは縦 1 列、ガイドはインカメを避けて左右へ分ける。**縦固定は方位合わせと、QR を読んでいる間だけ**（#130）。**2026-08-27 の横配置修正後は実機確認待ち** | [phone-ui](33_phone-ui.md) |
| 消灯と戻るキー | 観測中は**消灯させない**。戻るキーは 1 つ前へ、観測中だけ確認を挟む | [phone-ui](33_phone-ui.md) |
| API キー | リポジトリ直下の `.env`（`.gitignore` 済み）。**無くてもビルドは通す** | [CONTRIBUTING](../../CONTRIBUTING.md) |
| 人工衛星 | **星座と同じ星図に重ねる**（#36）。名前つきだけ・星より小さい点＋輪・名前は枠 2 つまで | [satellites](40_satellites.md) |
| 星座ガイド | 決めた順に案内して解説する。**60 秒で見つからない段は飛ばす**（止まらないことを優先） | [guide](37_guide.md) |
| **ガイドの文だけ AI に書かせてよい** | **作るときだけ通信し、再生時は一切通信しない。** 失敗・圏外なら同梱の 88 星座へ落ちる。**星座を選ぶのは端末** | [authoring](39_guide-authoring.md) |
| **toB の台本を QR で配る** | **Deflate → 生バイト 1 枚**（2,953 バイト・本文 200 字で 10 段）。Base64 を挟むと 5 段に落ちる。外した段は入れない | [authoring](39_guide-authoring.md) |
| **配った台本の編集可否** | 配るときに選ぶ（`locked`）。**これは鍵ではない**（QR は誰でも作れる）。編集すると出どころが「手で書いた」に変わり、元が残る | [authoring](39_guide-authoring.md) |
| 天体の案内 | `HOLD` の音声で1対象を指定。**場所・方角・案内を明示したときだけ**、通常表示の名前付き対象へ案内する（#46） | [object-guidance](36_object-guidance.md) / [narration](34_narration.md) |
| **案内は形と文字の両方で出す** | 矢印は**塗った面＋最上段の階調**、枠は**軸に沿った 120×56**。同時に**文字でも「左へ 32°」**を出す（2026-08-24 実機で「矢印が非常に分かりにくい」） | [glass-output](11_glass-output.md) / [pitfalls](72_pitfalls.md) |
| **録れた音は端末の推測で捨てない** | 声として数えた時間が 0ms でも文字起こしへ送る。**2 回目の長押しは「これを送る」という意思表示**。拾えたら画面の文字を「聞こえています」へ書き換える | [pitfalls](72_pitfalls.md) |

## 未決定事項

- 決まったらこのファイルを更新する。**エージェントは勝手に埋めない**

### ジェスチャーと入力

- **3 枠（`SINGLE_TAP` / `DOUBLE_TAP` / `HOLD`）がすべて埋まっている**（ホーム・解説・声の質問）。
  ガイド中だけ意味を入れ替えている（[guide](37_guide.md)）。**枠を増やす手立ては無いまま**
- **「触れている間だけ録音」は SDK 0.7.3 では不可。** `HOLD` しか届かず、押下開始・指を離したイベントが無い。
  代わりに **`HOLD` で開始し、もう一度の `HOLD` で送信**する
- **暗騒音から決めたしきい値が屋外で足りるか**。ログの「暗騒音○→しきい値○」と「声○ms」を突き合わせる
- **マイクと星図が同じ BLE を食い合う**（録っている間は星図を送らない、で回避中）

### 星座と衛星

- **パス予報をやり直すか**（2026-08-26 に撤去）。**やるなら先に決めるのは出す口**で、
  枠が 3 つとも埋まっている以上、スマホ側か画面の中に置くことになる（[satellites](40_satellites.md)）
- **星が無い空で方角の手がかりが足りるか**（衛星モードは星を描かない）
- **ガイド 1 本の長さと段の数**（即興は 3〜5、詳細は QR が許すかぎり。実機で首がどれだけ疲れるか分かっていない）
- **QR を紙に印刷して読めるか**（**画面に出したものは 2026-08-25 に 1 枚で読めた。** 紙は未確認・[authoring](39_guide-authoring.md)）

### 星空の再現（#45・[詳細](38_sky-simulation.md)）

- **年だけ指定して昼になったとき**どうするか（「1 万年前」→ いまの時分が昼）
- **一口メモ・流星群・今夜見た星座を再現時刻に合わせるか**（いまは実時間のまま）。
  **BGM の曲だけは再現時刻に追従している**（#69。星図と同じ太陽高度で選ぶため）
- **1 万年より前へ広げるか**（長期歳差は ±200,000 年持つが、固有運動の線形外挿が先に崩れる）

### 出力とファーム

- **`FEATURE_VERSION` が読めないので、退路への切り替えをどう判定するか**
- **0.6.0 のキャンバス画像 8 枚を使うか**（分割しても総量は減らない）
- **首を振っている間に漏れるドリフト**（2 秒の首振りで 1.5°）を詰めるか
- **消灯時間・通知の抑止**をアプリが書き換えるか、ユーザーに任せるか
- 明るさのキャンバスでの反映は **team-e 実機で確認待ち**

### アプリ

- **BGM と読み上げのつり合いを実機で詰める**（合わせたのは Mac のスピーカー。本番は屋外のスマホ）
- **AI 音声経路を実機で詰める**（受信時間・PCM 長・再生時間・`underrunCount` をログで見る）
- **観測地の測位を続けるか**（いまは画面に入ったとき 1 回だけ）
- **ホームのひとことが鯖江固定のままでよいか**（`GlassesApp` は測位前に作るので既定値を使う）。流星群の予告（#70）は場所を使わないので影響しないが、**空の暗さと惑星のメモは緯度でずれる**
- **本番配布するなら OpenAI をバックエンド経由にする必要がある**（いまは APK にキーが埋まる）
- **方位合わせの縦固定を続けるか**（センサーは横でも同じ方位を返す。Android 16 の大画面では固定が効かない・#165）
