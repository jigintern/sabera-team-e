# 音（読み上げと BGM）

- **グラスにスピーカーは無い**（[SDK とハードの制約](01_sdk.md)）
- **音はスマホから鳴らす** 目指しているのはミニプラネタリウムで、**黙るのは機能の欠落**として扱う
- 何を喋るかは [解説と声](06_narration.md)を参照
- 画面の流れは [画面遷移とジェスチャー](05_app-flow.md)を参照

## 声（読み上げ）

- **目指しているのはミニプラネタリウム**
- 端末の `TextToSpeech` は棒読みで、内容が合っていても雰囲気が壊れるため、**普段は OpenAI の音声で喋る**

| | 使うもの | 話し方 |
|---|---|---|
| **既定** | **`gpt-4o-mini-tts` / `alloy`** | `instructions` は「演じずに、ふだんの落ち着いた話し方」だけ |
| 退路 | Android の `TextToSpeech` | 棒読み。**圏外・キー未設定・API 失敗のとき自動で落ちる** |

- **話し方を文章で注文できることが `gpt-4o-mini-tts` を選んだ理由**
  - `tts-1` / `tts-1-hd` は `instructions` を解さないので、指定すると棒読みに戻る
  - **形式は生の PCM**（24kHz / 16bit little-endian / モノラル）
  - HTTP の読み出しは奇数バイトで
  切れることがあるため、余った 1 バイトを次のチャンクへ持ち越して必ずフレーム境界を守る
- **1 文ぶんを受信し終えてから`AudioTrack.MODE_STATIC` で再生する** 
  - ネットワークを直接
  `AudioTrack` へ流す方式はアンダーランと1バイトずれが大きなノイズになるため廃止した
  - 現在文の再生中に次文を先読みするので、全文の受信完了までは待たない
  - PCM キャッシュは偶数長を検証し、一時ファイルから原子的に置き換える。旧形式・破損キャッシュは使わない
- **「〇〇座ですね」はタップより先に作っておく**  
  - 星図を送った時点で視野の星座は分かっているので、その一言だけ先に合成してキャッシュに置く
  - **短い定型文なので 2 回目からは通信も要らない**
- 同じ星座の先読みが終わる前に星図が更新されても、**同じTTS通信は1本だけ**にする。
  タップされたときも進行中の先読みを待って使い、文章生成と回線を奪い合わせない
- 声は実機で聴き比べて **`alloy`** に決定した。`.env` の `OPENAI_TTS_VOICE` で差し替えられる
- 設定パネルの「声」で AI 音声と端末の読み上げを切り替えられる（聴き比べ用）
- **キャッシュは `cacheDir`**
  - PCM は 1 秒 48KB あるので **120 文字までの文**を残し、16MB で打ち切る
  - 48 文字にしていたときは**解説の各文（40〜80 文字）がほとんど残らず**、先読みも効かなかった
  - 解説文は 88 星座ぶんしか種類が無いので、1 文まるごと残せば 2 回目からは通信が要らない
- **同じ解説の中で声を入れ替えない**
  - 1 文でも端末の読み上げに落ちたら、**その解説は最後まで端末で通す**。
  - さらに**落ちてから 60 秒は AI 音声を試さない**ので、次の解説は頭から同じ声で揃う
  - 入れ替わると、同じ解説の途中で別の人が喋り出したように聞こえて話が切れる（実機・2026-08-22）
  - キャッシュに当たるぶんまで捨てることになるが、**声が揃うほうを採る**
- **端末の読み上げは日本語の男性の声を選ぶ**（`DeviceVoice`）
  - AI 音声が男性なので、落ちたときの差を小さくする。エンジンの声名に性別が入っていない端末では既定のまま
- `gpt-4o-audio-preview` に文章と音声を同時に作らせる案は採らなかった
  - **最初の一言を先に喋れなくなる**うえ、話し方の注文が効かない
- **注文を盛るとかえって芝居になる。** 
  - 「暗い場内で静かに語りかけるように」まで書いた版は聴き比べで落ちた
  - **望みは演技ではなく素の落ち着き**なので、演じないことだけ頼む

## BGM

- **アプリを開いた時点から鳴らす。** 星図以外の画面（ホーム・ガイド・接続・方位合わせ）も無音にしない
  - 以前は星図の画面が `Bgm` を持っていたので、**星図以外はすべて無音**で、星図に入った瞬間に音が始まっていた
  - **持ち主は `GlassesApp`。** 画面をまたいでも切れない（#69）
  - **星図だけを除ける**書き方にしてあるので、画面が増えても足す作業は要らない
- **解説していない間も鳴らす。** プラネタリウムの雰囲気は無音では出ない

### 場面と曲

**場面（`BgmScene`）と曲（`BgmTrack`）を分けてある。** 1 つの場面が複数の曲を持つ。

| 場面 | いつ | 曲 |
|---|---|---|
| 薄暮 | 太陽高度 −6° より上 | **Silver Blue Light**（静かで明るい）／**Light Awash**（ゆっくり満ちる） |
| 夜 | −6° より下 | **Fluidscape**（広くて何も無い）／**Ambiment**（遠くでピアノが鳴る） |
| ガイド | ガイドを再生している間 | **Drone in D**（低音が途切れない）／**Concentration**（言葉の邪魔をしない） |

- **時計で切り替えない**
  - 同じ 19 時が夏は明るく冬は暗い
  - **太陽高度（`SkyDarkness`）なら季節と緯度を勝手に吸収する**
  - 入口の画面では**まだ測位していない**ので既定の観測地で出す。薄暮か夜かを決めるだけなので足りる
  - 星図に入ったら測位済みの観測地の値で上書きするが、**1 回でも測るまでは押し付けない**
    （既定値が「夜」なので、薄暮に入ると夜の曲へ渡ってすぐ戻ることになる）
- **ガイドだけ専用の曲を当てる。** 喋っている時間が長く、**その間ずっと 28% に絞られている**ので、
  絞っても存在が消えない低音のあるものを選んだ
- 星図以外の画面に専用の曲は**持たせない**。星図と同じ束を鳴らし続けるほうが、進んでも音が切れない
- **場所・日時を指定している間は、その空の太陽高度で選ぶ**（#45）。
  星図と同じ `observationSnapshot()` を通るので、シドニーの朝を出していれば薄暮の曲になる。
  **一口メモ・流星群が実時間のままなのと揃っていない**（[index](00_index.md) の未決定事項）

### 曲を渡り歩く

- **120 秒を延々繰り返すと飽きる。** 場面まかせのときは、曲が終わる手前で次の曲へ渡る
- **同じ曲を続けて選ばない**（`BgmPlaylist`）。1 曲しか無い場面ではその曲を繰り返す
- **曲は 120 秒**
  - 末尾を先頭にクロスフェードして焼いてあるので、繰り返しても継ぎ目が出ない
  - 作り方は `tools/build-bgm.sh`（切り出し位置・音量の揃え方・エンコード条件）
  - 切り出し位置は `tools/pick-bgm-window.py` が数字で選ぶ。**耳では選んでいない。**
    ループの継ぎ目になる 2 か所の音量差がいちばん小さく、区間の揺れが少ないところを採る

### 入れ替えと音量

- **入れ替えはクロスフェード。** 片方を落としながらもう片方を上げる（3 秒）
  - 以前は 0 まで落としてから作り直していたので、**薄暮から夜へ変わるたびに約 3 秒黙っていた**
  - **曲送りも場面の入れ替えも同じ仕組みを通る**
  - 2 つの `MediaPlayer` を**同じオーディオセッション**に入れる。別々だと
    `LoudnessBoost` が片方にしか効かず、渡している最中に音量が動く
- **解説が始まったら 0.4 秒で 28% まで絞る**
  - 同じ音量だと言葉が埋もれてしまう
  - ただし 0 にはしない（曲が消えると解説だけ浮く）
- **BGM の既定音量は 75%**
  - 読み上げと BGM の音量は設定パネルのつまみで、値は端末に覚えさせる
  - **適正値は場所（屋外の暗騒音）と機種で変わる**うえ、合わせ直すのは夜の屋外になる
- **つまみを右端にしても足りない。** `AudioTrack.setVolume` も TTS の `KEY_PARAM_VOLUME` も
  `MediaPlayer.setVolume` も **1.0 が上限**なので、そこから上は `LoudnessEnhancer` で持ち上げる
  （`support/LoudnessBoost.kt`・**+6 dB**・実機未確認）。**読み上げと BGM に同じ量をかける**ので、
  解説中の絞り込み（28%）とのつり合いは変わらない。素の掛け算にしないのは**割れるから**で、
  効果を作れない端末では**音量が上がらないだけで今までどおり鳴る**

### 曲を選ぶ

- 設定パネルの「音」に**曲の指名**を置く。既定は**おまかせ**（場面まかせ）
- **指名するとその 1 曲だけを繰り返す。** 場面が変わっても入れ替わらない
- 場面ごとの見出しを付けて並べるのは、**おまかせのときに何が鳴るのかをそこで見せる**ため
- 覚えた名前は**知らないものなら null 扱い**（おまかせへ落ちる）。曲を差し替えても落ちない
