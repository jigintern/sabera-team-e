# 星座ガイド（受動的なツアー）

**決めた順に星座へ案内して、そのつど解説する。** 何を触ると始まるかは
[画面遷移とジェスチャー](05_app-flow.md)、何を喋るかは [解説と声](06_narration.md)、
案内の矢印と到着判定は [座標変換パイプライン](03_coordinate-system.md)。

## なぜ要るか

**いまのアプリは受け身。** 空を向いてタップして初めて「あれは何？」に答える。
**何を見ればいいか分からない人には、押すきっかけ自体が無い。**

台本を持たせておけば、アプリの側から連れて回れる。

| | 誰のため | 何をする |
|---|---|---|
| 台本の作成と再生 | 土台 | 作って保存し、観測中に受動的に流す |
| **即興ガイド（toC）** | 個人 | その場で作る。**電波があれば AI が書き、無ければ同梱を組む** |
| 詳細なカスタマイズ（toB） | 旅行会社・星空ツアー | 文面と順番まで作り込む。**エディタはまだ無い**（台本の形だけ用意した） |

## 台本のかたち

`guide/StarGuide.kt`。JSON で `filesDir/guides/<id>.json` に 1 本 1 ファイル
（`guide/GuideStore.kt`）。**`data/` には置かない**（あそこは生成物）。

| | |
|---|---|
| `title` / `summary` | 一覧の見出しと一行 |
| `origin` | **AI が書いたのか同梱を組んだのか。** あとから「なぜこの文なのか」を辿る |
| `steps[].targetName` | 星座名。**再生するその瞬間に**`guidanceTargets()` と突き合わせる |
| `steps[].intro` | 向く前に足す導入の一言。**方角と高さは書かない** |
| `steps[].body` | 向いたあとに読み上げる本文 |

- **方角と高度を台本に持たせない。** 書き置くと、別の日・別の場所で再生したとき嘘になる。
  「どちらを向けばよいか」は再生時に端末が作る（`ImpromptuGuide.intro`）
- **知らないキーが増えても読める。** 台本は端末に残り続けるので、後から足したキーで
  前の台本が開けなくなってはいけない
- **壊れた 1 本で一覧ごと開けなくしない。** 読めないものは黙って外す

## 再生（受動ガイド）

**新しい画面も新しい誘導処理も作っていない。** #46 の天体案内を順に呼ぶだけ。

```
「次は南の空の高いところ、さそり座です」を喋る   ← 方角はいまの空から作り直す
   ↓
beginGuidance(対象)          ← #46。矢印と「左へ 32°」が出て、主役以外の星座が薄くなる
   ↓
到着（5° に 0.5 秒）を待つ    ← 追従ループが Channel に 1 件流す
   ↓
本文を読み上げ、グラスの解説専用画面へ流す（#40）
   ↓
読み上げの終わりを待って次の段へ
```

### 文字でも読める（**声だけにしない**）

**ワンタップ解説とまったく同じ画面・同じ速さ**で流す（#40）。組版も速さも共用していて、
ガイド用の値は 1 つも持っていない。**騒がしい場所やイヤホンが無いときは文字が主役**になる。

```
探している間（星図＋矢印）              解説の間（解説専用画面）
┌───────── 576 ─────────┐          ┌───────── 576 ─────────┐
│  さそり座 南南西 高いところ │ ← 1 枠 │ さそり座 南南西 3/5    │ ← 見出し
│  左へ 32°                │ ← 2 枠 │ 狩人オリオンを刺した、 │
│      ·  ◀━━━━  ·        │          │ さそりの姿です。神話で │ ← 1 行ずつ上へ流す
└───────────────────────┘          └───────────────────────┘
```

| | |
|---|---|
| 探している間 | 案内のラベルに**方角と高さ**を足し、その下に**「左へ 32°」**を出す（`StarMap.withGuidanceLabel`）。**枠は 2 つ**。到着すると「このあたり」の 1 枠に戻る |
| 解説の間 | 見出しは**方角と進み具合**。**星座名は入れない**（`state.constellation` と連結されるので、入れると二重に出る） |
| 進むとき | **流し終わって余韻が過ぎるまで次の段へ進まない。** 首の上下フリックで読み直せば、そのぶん待つ |

- **見出しに高度を入れない。** 1 行 17 文字で切られるので、ワンタップと同じ「南南西 45°」に
  すると、いちばん長い「みなみのかんむり座」で 21 文字になり**進み具合から先に消える**。
  着いたあとに要るのは度数より、ツアーのどこにいるか
- **読み上げの終わりで進まない。** 字幕は 1 行流すごとに 6% ずつ遅くしてあるので、
  声が止まった時点で最後の数行はまだ出ていない。そこで進むと**読み切る前に消える**
- 畳む条件（字幕・読み上げ・声の質問・5 秒の余韻）はワンタップ解説がすでに持っているので、
  進行役は「解説画面から出た」ことだけを待つ。**待ち方の規則を 2 か所に置かない**
- **手で送ったときは待たない**（1 回タップの反応が鈍る）

| 場面 | どうするか |
|---|---|
| その星座が空に出ていない／低すぎる | **その段を飛ばす**（`GuidePlan.resolveSteps`。20° 未満は飛ばす） |
| 1 段も残らない | 「この台本の星座は、いまの空には出ていません」と喋って畳む |
| **60 秒で見つけられない** | **飛ばして次へ。** 探せない 1 つでツアーごと終わるほうが困る |
| **声で質問された**（`HOLD`） | 案内を畳んで答え、**答え終わったら同じ段からやり直す**（聞いたせいで見られなかったことにしない） |
| 読み上げの終わりを取り落とす | 90 秒で見切って次へ（**止まらないことを優先する**） |

- **解説した星座は今夜の記録に残す**（`support/NightRecord.kt`）。タップしたときと同じ扱いなので、
  スマホの「今夜見た星座」から本文を読み直せる
- 案内の終わりは `Channel`（`SharedFlow` は購読者がいない間の発行を捨てる）。
  **古い 1 件で次の段を飛ばさない**よう、案内を始める直前に汲み出す

### ジェスチャー（**ガイド中だけ入れ替える**）

| | ふだん | ガイド中 |
|---|---|---|
| `SINGLE_TAP` | 送信／解説の開始・停止 | **次の段へ**（録音中の送信だけは入れ替えない） |
| `DOUBLE_TAP` | 一口メモ | **いまの段をもう一度** |
| `HOLD` | 声で質問・天体を指定 | **据え置き。** ガイド中に浮かんだ疑問こそ聞きたい |

- **枠は増やしていない**（3 枠のまま）。ガイドを終えると元の割り当てに戻る
- **やめる口はスマホ**（上部バーの「ガイドを止める」と設定パネル）。
  グラス側に「やめる」を置くと、次へ送るつもりの 1 回でツアーが終わる
- **番号は進行役の外が持つ**（`guideIndex`）。手で送ったぶんと自動で進むぶんで
  **2 段飛ばない**ようにするため。進行役は「自分が足す前に番号が変わっていれば足さない」

## 即興ガイドを作る（toC）

**候補を選ぶのは端末。AI に選ばせない。** 空に出ていない星座を並べられると、
再生で全部飛んで「何も起きないガイド」になる。

候補は `StarMapRenderer.guidanceTargets()`（`SkyDensity.STANDARD`）の星座だけ。
**星図に線と名前が出る星座しか候補に入らない**ので、
「台本には載っているのにグラスには何も出ない」が起きない（#37 と同じ考え方）。

| テーマ | 選び方 |
|---|---|
| 今夜のおすすめ | 高いものから。**建物と木に邪魔されない順** |
| 明るくて探しやすい | その星座でいちばん明るい星が 2.0 等より明るいものだけ |
| 神話をたどる | 同梱の本文に物語があるもの。**「神話」の語では判定できない**（ポンプ座の本文は「神話は伝わっていません」） |
| 沈む前に見ておく | 西寄りで低いものから。**待つと見られなくなる順** |

- 3〜5 段。**次はいちばん近い星座へ送る**（南 → 北 → 南と振り回すと、
  方位補正がいちばん苦手な速い首振りが毎回入る）
- **テーマで 1 つも残らないなら、テーマを諦めて見やすいものを返す。**
  「今夜は作れません」と断るより、少し外れても回れるほうがよい

### AI に本文を書かせてよい条件

AGENTS.md は「解説文を AI に生成させる」を禁じている。理由は
**「星を見に行く場所ほど電波が届かない。いちばん要るときに一言も出せなかった」**。
ガイドはこの理由を壊さない形にしてあり、**次の 4 つが揃っているときだけ例外になる。**

1. **通信するのは台本を作るときだけ。** 出来た文は台本に焼き込むので、
   **再生時は圏外でも最後まで喋る**
2. **失敗・圏外・鍵なしなら同梱の 88 星座へ落ちる**（`GuideMaker`）。断って終わらせない
3. **星座を選ぶのは端末。** AI へ渡すのは端末が確定した並びだけで、AI は文を書くだけ
4. **返ってきた文は端末が検査する。** 記号と箇条書きを落とし（`AskGuard.sanitizeAnswer`）、
   グラスの解説画面に入る長さまで**文の切れ目で**切る

**半分だけ AI の文にしない。** 1 つでも星座が欠けたら台本ごと捨てて同梱で組み直す。
途中で口調が変わると、**別人が喋り出したように聞こえる**（06_narration.md と同じ理由）。

## スマホの画面

**作るのはホームから、再生は観測画面から。** 作るのは電波のあるうち、使うのは空の下。

| どこ | 何ができるか |
|---|---|
| ホーム →「ガイドを作る」（`ui/GuideScreen.kt`） | テーマを選んで作る・中身を読む・消す。**グラスは要らない** |
| 観測画面の畳んだ側 →「ガイドを始める」（`ui/component/GuideControls.kt`） | 台本を選ぶダイアログ → その場で始まる。**設定を開かない** |
| 観測画面の畳んだ側（ガイド中） | 進み具合・次へ・もう一度。**止めるのは主ボタン**（「ガイドを止める」） |

- **始める口は 1 つだけ。** 設定パネルの中に置いていたときは 3 手かかった。
  台本が増えてもボタンは 1 つのまま（選ぶのはダイアログ）で、**台本が無ければボタンも出さない**
- **作ったのに何も言わない画面にしない。** 何本目ができたか、AI と同梱のどちらで組んだかを出す
- 台本の中身は作った画面で読める。**何を喋るのか分からないまま外へ持ち出させない**
- 観測地は測位が取れていれば使い、無ければ既定の鯖江。
  数十 km ずれても**どの星座が空に出ているかはほとんど変わらない**

## まだ決めていないこと

- **toB の詳細エディタ。** 台本の形（`StarGuide`）は用意したが、書く画面はまだ無い。
  形が実機で固まってから作る（先に作ると、形が変わるたび UI ごと作り直しになる）
- **台本の受け渡し。** 旅行会社が配るには、ファイルか QR で入れる口が要る
- **1 本の長さと段の数**（いまは 3〜5。実機で首がどれだけ疲れるか分かっていない）
- **割り込みから戻ったとき、同じ段をやり直すのは冗長でないか**（いまは案内からやり直す）
