# デモ画像

**実機なしで作り直せる。** どれも**アプリと同じコードが描いたもの**で、絵に描き起こしたものではない。

```bash
tools/build-demo-images.sh      # 全部作り直す（グラス・スマホ）
```

**実機の写真ではない。** 出ないもの ——
パネルのにじみと明るさ・実機のフォント・BLE の転送時間・端末ごとの字送り・測位の結果。

## SABERA（かけている人に見えているもの）

| 画像 | 画面 | 出しているもの |
|---|---|---|
| `glass-splash.png` | 挨拶 | ロゴと今日のひとこと。**画像に焼く**（テキスト枠では字の大きさを変えられない） |
| `glass-calibration.png` | 方位合わせ | 十字だけ（128×128）。スマホの丸と重ねる |
| `glass-star-map.png` | 星図 | 星・星座線・星座絵と、名前のテキスト 8 枠 |
| `glass-satellites.png` | 星図＋人工衛星 | 点と輪郭と「あと何分」。**軌跡の線は引かない** |
| `glass-guidance.png` | 案内 | 星図の上に矢印の小画像を重ねる（星図は焼き直さない） |
| `glass-caption.png` | 解説 | 星図を消して 1 枚 3 行の字幕 |

- 広い視界（**仮に 92°**）の中へ、パネルの画角（**仮の 35°**）を正面より 11° 上に置いている
- 背景の空は**星図と同じ投影**で描いてあるので、星座線の頂点と空の星がつながる
- グラスの絵は塗りつぶさず**光として足す**（黒は光らないので下の景色が残る）
- 案内だけは**別々の画像 2 枚を 1 枚に合成**している（実機では同時に光っている）

## スマホ

| 画像 | 画面 |
|---|---|
| `phone-home.png` | 入口。今日のひとことと「スタート」 |
| `phone-connection.png` | 接続確認 |
| `phone-calibration.png` | 方位合わせ。**揃ったまま 2 秒で自動確定**（確定ボタンは無い） |
| `phone-star-map.png` | 観測中。グラスに出している星図をそのまま映す |
| `phone-sky-condition.png` | 星空の条件（場所・時代・時刻） |
| `phone-settings.png` | 設定 |
| `phone-developer.png` | 開発者用画面。数字とログはここだけ |
| `phone-guides.png` | 星座ガイドの一覧と作成 |
| `phone-guide-author.png` | 台本を手で書く（toB） |
| `phone-guide-share.png` | 台本を QR で配る |

- 星図のプレビューは**実際に描画されたもの**（偽の 6DoF を流してパイプラインを走らせている）
- **昼に作り直しても夜空になる。** アプリ自身の「星空の条件」でその日の 21 時へ寄せている
- 背景の星座は**さそり座に固定**してある（季節で変わると絵が揃わない）

## 中身の作り方

| どこ | 何をする |
|---|---|
| `PhoneScreenshotTest` | Robolectric でアプリの Compose を描き、`build/doc-images/phone/` へ PNG |
| `DocumentImagesTest` | グラスへ送るのと同じ画像とテキスト枠を `build/doc-images/panels.txt` へ |
| `tools/compose-glass-images.java` | それを空と街に重ねて `docs/images/` へ（文字を焼くのに AWT が要る） |

**`.env` に OpenAI のキーがあると、作り直しのあいだに読み上げの音声合成が走る**
（アプリが本当に喋るところまで動くため）。キーが無ければ端末の音声に落ちて通信はしない。
