# 星導

## 概要

- SABERA をかけて空を見上げると星座が重なり、見ている星空をハンズフリーで案内するアプリ
- ツルをダブルタップで、見ている星座の解説を聞く
- ツルを長押しして、星空について声で質問する
- 探したい星座をガイドする
- プラネタリウム風の BGM と、音声・テキストの解説
- 都市と日時を指定して、その場所の星空を再現する
- 星座の情報をアプリに同梱しているので、圏外でも案内できる
